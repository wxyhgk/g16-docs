### C.7 已修复的错误

以下错误已在 Rev. B.01 中修复:

- 修复了使用 SCF=QC 时在作业步骤中间从 RWF 重启的问题。
- 在执行 SCF=XQC 或 SCF=YQC 的常规 SCF 部分时,只有当找到新的最低能量波函数时才会保存轨道与密度。若 L502 未能收敛并转入 L508(QC 或最速下降 SCF),则使用常规 SCF 迭代中的最佳波函数。
- 修复了在 EOM-CC 计算中途从 RWF 重启时的问题。
- 修复了 ROMP4 以及 EOM-CC 在 β 自旋空间为空或 α 自旋空间已满时出现的问题。
- 更正了 G4 与 G4MP2 作业汇总表中错误的标签。
- 修复了当 RWF 被分割到多个物理文件中时,为 NBO 命名临时文件所出现的问题。
- 修复了一个内存分配问题,该问题导致在大分子上使用极少量内存进行 CIS 与 TD 频率作业时失败。这些作业现在可以完成,但若分配更多内存(即更大的 %Mem 值),它们将运行得更加高效。
- 修复了使用 FormCheck 关键字的作业失败的错误。该关键字已被弃用,更灵活的 -fchk 命令行选项是首选替代方案。
- 去除了 formchk 在处理包含 PCM 溶剂化计算的检查点文件时打印的不必要警告。
- 更正了 Opt=(TS,ReCalcFC=N) 的路由。
- 分子力学参数现在可以正确存储于格式化检查点文件中。
- 更正了使用 NBO6 进行相互作用删除(Pop=NBO6Del)的路由。
- 修复了一个错误,该错误导致在复合作业的后续步骤中无法启用 GPU。
- 更正了原子性质列表中解析已弃用关键字 QMom 与 Magneton 时的问题。
