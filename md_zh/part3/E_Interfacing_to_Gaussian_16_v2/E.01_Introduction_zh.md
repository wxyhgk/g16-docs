### E.1 简介

本文档介绍对接文件的第 2 版。有关与早期版本相比的变更,参见"发布历史"。在许多情形下,需要将 Gaussian 中的一项或多项计算作为更大任务的一部分来运行,并在 Gaussian 与任务的其他部分之间传递数据:

- *编写脚本以自动运行多个相关的 Gaussian 作业。* 这通常通过 shell 脚本,或使用 Python 与 Perl 等脚本语言编写的程序来完成。此处为更紧密集成的计算所提供的一些工具,对于此目的同样有用。
- *对 Gaussian 计算结果进行后处理。* 过去,格式化检查点文件(.fchk)一直是为此目的交换结果的标准方法。它非常适合可视化等分析任务,但由于下文所述的原因,不太适合数值密集型的后续计算。波函数(.wfn)文件为这些用途提供了一些额外信息,但与 .fchk 文件存在某些相同的局限。
- *利用 Gaussian 生成的中间数据,在其他程序中进行计算。* 这种策略避免了需要在其他程序中编写与 Gaussian 已有功能重复的代码。典型用途主要分为三类:
  - 运行生产性计算,将 Gaussian 的结果与独立程序的结果相结合。这些程序通常以 Fortran 或 C 等编译型语言实现。例如,价键法等 SCF 方法或某些特殊的 MCSCF 方法可以使用 Gaussian 计算的单电子与双电子积分。同样,后 SCF 方法可以使用 Gaussian 生成的分子轨道上所需的积分。
  - Gaussian 的基础架构也可以纳入外部程序的结果。例如,几何优化与 ONIOM 计算可以在 Gaussian 中利用外部程序提供的能量与力来完成(例如,使用 Gaussian 中不可用的理论方法计算得到)。

- 对新模型或新方法进行原型开发,实现可采用编译型语言,也可采用 Python 等解释型语言。若能使用 Gaussian 计算的全部量,则只需实现与调试新模型的独特部分,这会十分方便。
- 课堂练习,使用 Python 或 MatLab 等解释型语言创建,使练习能够聚焦于某一特定问题,而无需提供无关部分的代码(例如,编写简单的 SCF 算法而无需计算积分)。有若干方法可以促进此类通信,数据可流入 Gaussian(来自另一来源)、从 Gaussian 流向另一程序,或两者兼有。该过程可由 Gaussian 控制、由脚本控制,或由另一程序控制。一般而言,数据交换通过一种称为 *矩阵元(matrix element)文件* 的文本文件进行。其结构被设计得非常通用。*提供了一些接口例程*;它们以开源软件实现,因此也可用于用户程序与其他量子化学软件包之间的通信。矩阵元文件是与外部程序交换中间结果的推荐工具,因为所有量均以完整精度包含在内。对于可视化、后处理以及只需中等有效位数或希望使用纯文本文件的其他情形,格式化检查点文件仍是更简单且与机器无关的选择。
