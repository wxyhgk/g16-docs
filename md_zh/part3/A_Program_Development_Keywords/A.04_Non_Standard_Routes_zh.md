### A.4 Non-Standard Routes(非标准路由)

若所需的选项或链接组合与标准路由相差甚远,则可以读入一整套覆盖(overlay)与链接的序列及其相关选项。作业类型输入段以如下一行开始:

```
#NonStd
```

随后每个所需的覆盖占一行,按执行顺序给出:覆盖编号、斜杠、所需选项、另一个斜杠、待执行的链接列表,最后以分号结束:*Ov/Opt=val,Opt=val,*···*/Link,Link,*···*;* 例如:

```
7/5=3,7=4/2,3,16;
```

表示依次执行链接 702、703 和 716(按此顺序),并且在每个链接中将选项 5 设为 3、选项 7 设为 4。若所有选项均为默认值,则该行写为

```
7//2,3,16;
```

路由规格还有一个特性是跳转编号。它以圆括号给出,位于链接列表末尾、分号之前。它指明当前覆盖完成后应执行哪一行覆盖。若省略,则默认值为 +0,表示程序将继续执行列表中的下一行(不跳过任何行)。若跳转编号设为 -4,如

```
7//2,3,16(-4);
```

则执行将转到向上数第四条路由行(不计当前行)所对应的覆盖。此特性允许在路由中构建循环,对优化计算十分有用。程序中链接调用例程的一个参数可以覆盖跳转。在几何优化中即利用此机制,在一系列覆盖行上循环,直至优化完成,此时执行循环之后的那一行。注意,非标准路由通常并非从头创建,而是通过打印并修改与所需路由最相似的标准路由所生成的序列来构建。使用 testrt 实用程序最容易完成此操作。**简单路由示例。** 标准路由:

```
#RHF/STO-3G
```

会生成以下非标准路由:

1`1/38=1/1;` 2`2/12=2,17=6,18=5,40=1/2;`

```
3/6=3,11=1,16=1,25=1,30=1,116=1/1,2,3; 3
```
