### 3.1 语法

Gaussian 16 的输入由 ASCII 文本文件中的一系列行组成。Gaussian 输入文件的基本结构包括若干不同的部分:

- *Link 0 命令*:指定并命名临时文件(不以空行结束)。
- *路由段*(以 *#* 开头的行):指定所需的计算类型、模型化学及其他选项(以空行结束)。有关 Gaussian 16 功能的信息,请参见模型化学与作业类型。
- *标题段*:对计算的简要描述(以空行结束)。输入中必须包含此部分,但 Gaussian 16 程序不会对其作任何解释。它会出现在输出中,用于标识和说明计算。通常,此部分可包含化合物名称、对称性、电子态以及其他相关信息。标题段不得超过五行,且必须以空行结束。标题段中应避免使用以下字符:@ # ! – _ \ *控制字符*(*尤其是* Ctrl-G)
- *分子规范*:指定待研究的分子体系(以空行结束)。完整信息请参见分子规范。
- *可选的附加部分*:特定作业类型所需的附加输入(通常以空行结束)。

许多 Gaussian 16 作业只包含第二、第三和第四部分。以下是此类文件的示例,它请求对水分子进行单点能量计算:`# HF/6-31G(d)`*路由段*

`water energy` *标题段*

`01` *分子规范*

```
O-0.4640.1770.0
H-0.4641.1370.0
```

![](../../../md/images/part1/p027_5.jpeg)

```
H0.441-0.1430.0
```

在此作业中,路由段与标题段各只有一行。分子规范部分以一行开始,给出分子的电荷与自旋多重度:本例中电荷为 0(中性分子),自旋多重度为 1(单重态)。电荷与自旋多重度行之后,为描述分子中各原子位置的行;本例使用笛卡尔坐标来表示。分子规范将在本章后文中更详细地讨论。下面的输入文件演示了 Link 0 命令及一个附加输入部分的用法:`%Chk=heavy` *Link 0 部分* `# HF/6-31G(d) Opt=ModRedun` *路由段*

`Opt job` *标题段* *分子规范部分*`01` *原子坐标*···

`3 8` *向几何优化过程中使用的内坐标中添加一个键和一个键角*`2 1 3`

该作业请求进行几何优化。分子规范之后的输入部分供 Opt=ModRedundant 关键字使用,用于在几何优化所用的内坐标中额外添加一个键和一个键角。该作业还为检查点文件指定了名称。为方便查阅,"节的顺序"一节中的表格列出了 Gaussian 16 输入文件中可能出现的全部部分及其相关关键字。

#### 3.1.1 语法规则

一般而言,Gaussian 输入需遵守以下语法规则:

- 输入为自由格式,且不区分大小写。
- 空格、制表符、逗号或正斜杠可以任意组合使用,以分隔一行中的各项。多个空格视为单一分隔符。
- 关键字的选项可以采用以下任一形式指定:
- *keyword = option*
- *keyword(option)*
- *keyword=(option1, option2,* ···*)*
- *keyword(option1, option2,* ···*)*
- 多个选项置于圆括号中,并以任一有效分隔符分隔(常用逗号,上文已示出)。选项左括号前的等号可以省略,或者可在其前后选择性地加入空格。注意,某些选项还带有取值;此时选项名后接一个等号,例如:CBSExtrap(NMin=6)。
- 所有关键字与选项都可以缩写为整个 Gaussian 16 系统中的最短唯一缩写。因此,SCF 关键字的 Conventional 选项可缩写为 Conven,但不能缩写为 Conv(因为存在 Convergence 选项)。无论 Conventional 与 Convergence 是否同时是某一关键字的有效选项,此规则均成立。
- 外部文件的内容可以使用以下语法包含在 Gaussian 16 输入文件中:*@filename*。这会将整个文件置于输入流的当前位置。在此类命令后附加 /N 将阻止包含文件的内容在输出文件开头被回显。
- 注释以感叹号(!)开始,可出现在行中的任何位置。独立的注释行可出现在输入文件的任何位置。
