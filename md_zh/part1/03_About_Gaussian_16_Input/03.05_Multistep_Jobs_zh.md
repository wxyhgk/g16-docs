### 3.5 多步任务(Multistep Jobs)

多个 Gaussian 任务可以组合在同一个输入文件中。每个后续任务的输入与前一任务步骤之间,以如下形式的一行分隔:

```
--Link1--
```

下面是一个包含两个任务步骤的输入文件示例:

```
%Chk=freq
#HF/6-31G(d)Freq
FrequenciesatSTP
```

*分子定义*

```
--Link1--
%Chk=freq
%NoSave
#HF/6-31G(d)Geom=CheckGuess=ReadFreq=(ReadFC,ReadIsotopes)
Frequenciesat300K
```

*电荷与自旋*

```
300.02.0
```

*同位素定义*

该输入文件分两次计算振动频率并进行热力学分析,两次的温度与压力不同:首先为 298.15 K、1 个大气压,然后为 300 K、2 个大气压。注意,--Link1-- 行之前必须有一个空行。
