### 4.8 设置默认值

此处提到的 Link 0 命令的默认值可以在 *Default.Route* 文件中设置。也可以通过环境变量和命令行进行设置。下表列出了这些设置之间的对应关系:

**Link 0 Default.Route 选项 环境变量 说明**

%CPU-C--c=*list* GAUSS_CDEF 多处理器并行作业的处理器/核心列表。%GPUCPU-G--g=*list* GAUSS_GDEF GPU 并行作业的 GPU=核心列表。%Mem-M--m=*value* GAUSS_MDEF Gaussian 作业的内存量。%NProcShared-P--p=*n* GAUSS_PDEF 多处理器并行作业的处理器/核心数。在大多数情况下已由 %CPU 取代。%UseRSH-S- rsh-s=rsh GAUSS_SDEF=rsh 使用 rsh 启动网络并行作业的工作进程。%UseSSH-S- ssh-s=ssh GAUSS_SDEF=ssh 使用 ssh 启动网络并行作业的工作进程。%LindaWorkers -W--w=*list* GAUSS_WDEF 网络并行作业的主机名列表。%DebugLinda GAUSS_LFLAGS=-v 启用详细的 Linda 输出。

命令行参数值中包含特殊字符时,必须加上引号。

注意,上述环境变量的设置使用的是 bash 语法。所有 Link 0 命令的完整文档请参见 Link0。
