### 4.3 临时文件

Gaussian 在计算过程中使用若干临时文件,包括:

- 检查点文件:*name*.chk
- 读写文件:*name*.rwf
- 双电子积分文件:*name*.int(默认为空)
- 双电子积分导数文件:*name*.d2e(默认为空)
- 临时文件:*name*.skr

默认情况下,临时文件在运行成功结束时被删除。但是,您可能希望保存检查点文件,以便在另一个 Gaussian 作业中使用、供可视化程序使用,或用于重启失败的作业等。这可以通过在 Gaussian 输入文件中使用 %Chk 命令为检查点文件*命名*来实现,即指定明确的文件名和/或存放位置。示例如下:

```
%Chk=water
```

该命令应置于输入文件的最开头(路由段之前),它会将检查点文件命名为 water.chk,覆盖通常生成的文件名,并使该文件在作业结束时被保存。此时文件位于当前目录中。但是,如下命令既可以指定文件名,也可以指定备用目录位置:

```
%Chk=/chem/scratch2/water
```

成功完成的作业会自动删除临时文件,但若作业被外部终止或以其他方式异常结束,则这些文件不会被删除。因此,遗留文件可能会在临时目录中逐渐积累。避免杂乱文件过多的一个简便方法,是让所有用户共享一个公共临时目录,并在系统启动脚本(例如 /etc/rc 或 /etc/rc.d/rc3.d 下的某个文件)中加入 rm 命令,使该目录在系统启动时被清空。若使用 NQS 批处理系统,还应在启动 NQS 之前清空临时目录,以确保清空时没有作业正在使用该目录。如果临时目录的磁盘空间有限,但系统其他位置仍有可用空间,您可能希望将各个临时文件分散到多个磁盘位置。以下命令可用于指定其他临时文件的名称和位置:

%RWF=*pathRead-Write file* %Int=*pathIntegral file* %D2E=*pathIntegral Derivative file*

一般而言,读写文件是迄今为止最大的文件,因此最常为其指定备用位置。

#### 4.3.1 将临时文件分布到多个磁盘

提供了一种替代语法,可将读写文件、积分文件和/或积分导数文件分布到两个或多个磁盘(或文件系统)上。%RWF 命令的语法为:%RWF=*loc1,size1,loc2,size2*, ··· 其中每个 *loc* 为目录位置或文件路径名,每个 *size* 为该位置文件段的最大大小。对于仅指定目录的 *loc*,Gaussian 将自动生成唯一的文件名。在 UNIX 系统上,仅指定目录(不含文件名)时必须以结尾斜杠结束。默认情况下,大小以 8 字节字为单位。该数值后还可紧跟 KB、MB、GB、TB、KW、MW、GW 或 TW(中间不留空格),以指定千字节、兆字节、吉字节、太字节或千字、兆字、吉字、太字为单位。注意 1 MB = 1024² 字节 = 1,048,576 字节(而非 1,000,000 字节)。

任一大小参数设为 -1 表示可使用所有可用空间,设为 0 则表示使用现有文件段的当前大小。-1 仅适用于所指定的最后一个文件,且为其默认值。例如,以下指令将读写文件分布到三个磁盘上:

```
%RWF=/dalton/s0/,4GB,/scratch/,3GB,/temp/s0/my_job,-1
```

这三个文件段的最大大小分别为 4 GB、3 GB 和无限制。Gaussian 将为前两个段生成名称,第三个段将被命名为 my_job。注意,目录说明必须以结尾斜杠结束。由于当前 UNIX 实现的限制,应谨慎使用 -1,因为它会尝试将文件段扩展到这些系统上所有剩余的磁盘空间;使用它还会产生一个副作用:列表中其后的任何其他文件段将永远无法被使用。在 32 位操作系统下,Gaussian 16 可寻址的单个临时文件最大为 16 GB。没有必要将临时文件拆分为 2 GB 的文件。然而,16 GB 的临时空间总上限源于 32 位整数的固有限制,拆分临时文件并不能突破该限制。

#### 4.3.2 保存与删除临时文件

默认情况下,未命名的临时文件在 Gaussian 运行结束时被删除,而已命名的文件则会被保存。%NoSave 命令可用于更改此默认行为。在输入文件中包含该指令时,指令出现在 %NoSave *之前*的已命名临时文件将在运行结束时被删除(所有未命名的临时文件同样会被删除)。但是,若为某文件命名的 % 指令出现在 %NoSave 指令*之后*,则该文件将被保留。例如,以下命令为检查点文件指定了名称,为读写文件指定了另一个名称和备用目录位置,并使得在 Gaussian 作业结束时仅保存检查点文件:

```
%RWF=/chem/scratch2/water Files to be deleted go here.
%NoSave
%Chk=water Files to be saved go here.
```

注意,作业异常终止时,所有文件都会被保存。
