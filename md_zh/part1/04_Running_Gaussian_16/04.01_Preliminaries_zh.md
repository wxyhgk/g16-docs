### 4.1 预备知识

#### 4.1.1 系统要求

- Gaussian 目录需要约 2–3 GB 的磁盘空间用于存放可执行文件,具体取决于计算机系统。
- Gaussian 16 的默认内存分配为 800 MB。程序中较大的固定维度需要 1–2 GB 的交换空间(swap space)。当作业通过 %Mem Link 0 命令或 *Default.Route* 文件中的 -M- 命令请求更多内存时,还需要额外的交换空间。以上要求适用于*每个*同时运行的作业。
- 请参阅随光盘附带的平台列表。本文档的最新版本可始终在 `www.gaussian.com/g16/g16_plat.pdf` 获取。

#### 4.1.2 配置 Gaussian 运行环境

Gaussian 通过若干环境变量指定的目录来查找可执行文件并创建临时文件。用户负责定义其中两个:

- g16root:指定 g16 子目录所在的目录(即其上一级目录)。
- GAUSS_SCRDIR:指定应用于存放临时文件的目录。

#### 4.1.3 初始化文件

Gaussian 系统包含用于设置用户运行环境的初始化文件。这些文件为:`$g16root/g16/bsd/g16.login` *C shell* `$g16root/g16/bsd/g16.profile` *Bourne shell*

通常在 Gaussian 用户的 .login 或 .profile 文件中加入类似以下的内容: *.login 文件:*

![](../../../md/images/part1/p047_6.jpeg)

```
setenvg16root/location
source$g16root/g16/bsd/g16.login
setenvGAUSS_SCRDIR/path
```

*.profile 文件:*

```
exportg16root=/location
.$g16root/g16/bsd/g16.profile
exportGAUSS_SCRDIR=/location
```

设置正确后,即可使用 g16 命令运行 Gaussian 16。

#### 4.1.4 环境变量参考

由 g16.login 和 g16.profile 创建的环境变量包括:

- GAUSS_EXEDIR:指定存放 Gaussian 可执行映像的目录。默认包括主目录 $g16root/g16 以及若干备用目录。
- GAUSS_ARCHDIR:指定存放全局归档文件的目录,若主归档不可用,临时归档文件也应放置于此。若未设置,默认为 $g16root/g16/arch。
- G16BASIS:包含 Gaussian 内置标准基组文件的目录,以及以通用基组输入形式提供的若干附加基组。该环境变量为方便使用而设置,并配合 @ include 机制使用。
- Gaussian 的默认值可以通过形式为 GAUSS_*x*_DEF 的环境变量设置。详情参见 *Default.Route* 文件的文档。
- 使用 Linda 进行网络/集群并行计算时,还可以使用 GAUSS_LFLAGS 环境变量向 Linda 进程传递选项。详见"并行作业"。
