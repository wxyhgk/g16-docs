### 4.7 g16 命令行选项

g16 命令在所有平台上均接受以下选项:

**选项 说明 示例**

-r=*list* 路由段默认关键字列表`-r="Int=SuperFine Freq=HPModes"` -m=*value* Gaussian 作业的内存量`-m=200GB` -c=*list* 多处理器并行作业的处理器/核心列表`-c="0-31"` -g=*list* GPU 并行作业的 GPU=核心列表`-g="0-8=0-6,31,32"` -s=*command* 用于启动网络并行作业工作进程的命令,为 ssh 或 rsh 之一`-s=ssh` -w=*list* 网络并行作业的主机名列表。`-w="apple,banana,cherry"`

-p 多处理器并行作业的处理器/核心数。已弃用;请改用 -c。 -l 网络并行作业的节点数。已弃用;请改用 -w。 -x 作业的完整路由段(不从输入文件中读取路由段)`-x="# b3lyp/6-31G(d) opt freq"` -y 检查点文件。`-y="$HOME/project3/gfp.chk"` -fchk 生成指定的格式化检查点文件,并同时生成二进制检查点文件,每次更新检查点文件时同步更新它。`-fchk=/plots/job8.fchk` -z 读写文件。`-z=/scratch2/fox7.rwf` -ic 读取输入所用的已有检查点文件。`-ic=job6` -im 读取输入所用的矩阵元文件。`-im=fox7.dat` -im4 读取输入所用的、使用 4 字节整数的矩阵元文件。`-im4=fox12` -ir 读取输入所用的原始矩阵元文件。`-ir=job6` -ir4 读取输入所用的、使用 4 字节整数的原始矩阵元文件。`-ir4=job27` -oc 输出检查点文件。通常与 -y 冗余。 -om 输出矩阵元文件。`-om=job16new_mat`

```
-om4=job32mat -om4 Output matrix element file using 4-byte integers.
```

-or 输出原始矩阵元文件。`-or=job7_raw` -or4 输出使用 4 字节整数的原始矩阵元文件。`-or4=proteins_rawdat`

注意,选项值通常需要加上引号,以避免被 shell 修改。
