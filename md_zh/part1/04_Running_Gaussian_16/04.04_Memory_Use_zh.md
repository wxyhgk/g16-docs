### 4.4 内存使用

%Mem 命令控制 Gaussian 使用的动态内存量。默认情况下使用 800 MB(100 MW)。可以通过指定一个数值并紧跟 KB、MB、GB、TB、KW、MW、GW 或 TW(中间不留空格)来改为其他值,以指定千字节、兆字节、吉字节、太字节或千字、兆字、吉字、太字为单位。默认单位为兆字(megawords)。例如,以下命令同样将动态内存量设为 1 GB:

```
%Mem=1GB
```

对于非常大的直接 SCF 计算,可能需要更大的内存分配,至少为 3*N*² 个字,其中 *N* 为基函数的数目。*警告:请求的内存量超过计算机实际可用的物理内存,将导致性能严重下降。* 如果 Gaussian 运行在物理内存有限的机器上,以致无法提供默认的内存量,则默认算法及默认内存分配将在安装时被相应地设置。
