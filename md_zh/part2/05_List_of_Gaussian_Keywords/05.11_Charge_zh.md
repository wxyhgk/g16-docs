### 5.11 Charge(背景电荷)

Charge 关键字要求在计算中包含一个背景电荷分布。该电荷分布由点电荷构成 [196, 197]。

#### 5.11.1 输入

默认情况下,电荷从输入流中读取,每行一个,格式如下:

```
xyzcharge
```

其中 `x`、`y`、`z` 为标准取向下的坐标(单位由 Units 关键字指定,默认为埃),`charge` 为电荷值。

#### 5.11.2 选项

**Angstroms**

表示输入的电荷位置以埃为单位指定。

**Bohrs**

表示输入的电荷位置以玻尔为单位指定。

**Check**

从检查点文件中读取背景电荷分布。

#### 5.11.3 可用性

单点能、几何优化和频率计算。不适用于半经验方法或 PBC。

#### 5.11.4 相关关键字

Units

#### 5.11.5 示例

要在存在背景电荷的情况下进行几何优化,必须使用 Opt=Z-Matrix NoSymm 关键字,并以传统的 Z 矩阵坐标或符号化笛卡尔坐标定义输入几何。示例如下:

```
#B3LYP/6=31G(d)Opt=Z-MatrixChargeNoSymm
Waterwithpointcharges
0,1
O-0.75-0.940.0
H0.21-0.940.0
H-1.07-0.00.0
```

```
2.02.02.01.2
2.0-2.02.01.1
```
