### 5.10 CCD and CCSD(CCD 与 CCSD)

这些方法关键字用于请求耦合簇计算 [187]:CCD 使用从 Hartree-Fock 行列式出发的双激发 [188],CCSD 则同时使用单激发和双激发 [189–192]。CC 与 QCID 是 CCD 的同义词。RO 可与 CCSD 组合使用,进行限制性开壳层能量计算 [193]。

#### 5.10.1 选项

**FC**

该关键字可使用所有冻结核选项;默认进行冻结核计算。完整信息参见 FC 选项的讨论。

**T**

以非迭代方式包括三重激发 [190, 194](仅适用于 CCSD)。CCSD-T 是 CCSD(T) 的同义词。

**E4T**

与 T 选项一起使用,请求对完整的 MP4 以及 CCSD(T) 均包括三重激发。

**T1Diag**

计算 T. J. Lee 及其同事提出的 T 的 T1 诊断量 [195](仅适用于 CCSD)。

**Conver=_N_**

将能量的收敛判据设为 10−*N*,波函数的收敛判据设为 10−(*N*−2)。单点计算的默认值为 *N*=7,梯度计算的默认值为 *N*=8。

**MaxCyc=_N_**

指定 CCSD 计算的最大循环数。

**TWInCore**

是否在高阶 post-SCF 计算过程中将振幅及其乘积存储在内存中。默认情况下,若内存足够则存储在内存中,否则使用磁盘。TWInCore 会在内存无法容纳这些数据时使程序终止,而 NoTWInCore 则禁止在内存中存储。

**SaveAmplitudes**

将收敛的振幅保存在检查点文件中,供后续计算使用(例如,使用更大的基组)。使用此选项会产生非常大的检查点文件,但也可能显著加快后续计算。

**ReadAmplitudes**

从检查点文件(若存在)中读取收敛的振幅。注意,新计算可以使用与原计算不同的基组、方法(若适用)等。

#### 5.10.2 可用性

CCD 与 CCSD 的解析能量和梯度,CCSD(T) 的数值梯度,以及所有方法的数值频率。限制性开壳层(RO)方法可用于 CCSD 与 CCSD(T) 能量计算。

#### 5.10.3 相关关键字

MP4, Transformation

#### 5.10.4 示例

在最后一次相关迭代之后,耦合簇能量在输出中如下出现。第一行给出 CCSD 能量,最后一行给出包括非迭代三重激发贡献的能量:

```
Wavefunctionamplitudesconverged.E(Corr)=-75.001924366
```

···

```
CCSD(T)=-0.75002048348D+02
```

CCSD 能量标记为 `E(CORR)`,包括非迭代三重激发贡献的能量在最后一行给出。
