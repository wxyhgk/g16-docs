### 5.26 EPT(电子传播子理论)

该方法关键字请求进行电子传播子理论(electron propagator theory)[368] 计算,用于获得相关电子亲和能与电离势 [369–383]。Gaussian 16 包含 Ortiz 提出的重整化部分三阶近似(renormalized partial third order approximation,P3+)方法 [384]。它还对复合电子传播子(composite electron propagator,CEP)方法中对角二阶自能近似(diagonal, second-order self-energy approximation,D2)部分做了算法改进,可显著加速计算,详见 [385]。这些模型将相对廉价的 D2 级别计算(使用大基组,例如增广四zeta或三zeta基组)与代价更高的 P3+ 或 OVGF 计算(使用较小基组,例如三zeta或二zeta基组)相结合,从而得到高精度的预测。

EPT 方法及其应用的综述参见 [343, 386]。EPT 计算默认保存 <ia||bc> 积分,但可以使用 Trans=Full 以更多磁盘占用换取更短的 CPU 时间,或使用 Trans=IJAB 以更多 CPU 时间换取更少的磁盘占用。在后一种情况下,不计算电子亲和能。默认只计算小于 20 eV 的电离势。使用 ReadOrbitals 选项可以输入需要精修的起始与终止轨道。OVGF 是此关键字的同义词。

#### 5.26.1 选项

**OVGF**

使用外价格林函数传播子(Outer Valence Green's Function propagator)。这是默认选项。

**P3**

使用 P3 与 P3+ 传播子。

**OVGF+P3**

同时使用两种传播子方法。

**D2**

使用对此情形非常高效的代码执行二阶电子传播子计算。D2 同时计算从所有轨道的得电子(电子亲和能)与失电子(电离势)过程,而 D2IA 仅计算从活性(非冻结芯)轨道的电离,计算代价更低。该选项常作为复合方法的一部分,与使用较小基组的高阶 EPT 计算配合使用。EP2 与 EP2IA 分别为这两个选项的同义词。

**FC**

此关键字可以使用所有冻结芯选项;默认进行冻结芯计算。完整信息参见 *FC 选项* 的讨论。

**ReadOrbitals**

在单独的、以空行结束的输入段中,指定需要精修的起始与终止轨道。对于非限制性计算,α 与 β 轨道分别指定范围(在同一输入行上)。轨道编号从冻结芯之后的第一个活性轨道开始计数。例如,对于乙烯采用默认冻结芯时,输入 3 8 将跳过两个 2s 价轨道(另外还跳过两个冻结的 1s 芯轨道),因此在输出中 HOMO 将被标记为轨道 6。

**ForceSort**

即使不必要,也强制对中间量进行排序。此选项出现在一些 Gaussian 测试作业中,但对于生产计算并无用处。

#### 5.26.2 可用性

以 HF 作为参考方法的单点能量计算。
