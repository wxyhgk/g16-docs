### 5.48 IRCMax(IRC 最大能量点计算)

使用 Petersson 及其同事的方法 [509–517] 执行 IRCMax 计算。以过渡结构为输入,该计算类型使用 GS2 算法 [507, 508](详见 IRC=GS2)沿指定反应路径寻找能量极大值。IRCMax 需要两个模型化学作为其选项,二者以冒号分隔:IRCMax(*model2*:*model1*),例如 IRCMax(B3LYP/6-31G(d,p):HF/6-31G(d,p))

#### 5.48.1 选项

ZC-VTST 选项

**Zero**

在 IRCMax 计算中包含零点能。

路径选择选项

**Forward**

仅沿正向追踪路径。

**Reverse**

仅沿反向追踪路径。

**ReadVector**

读入待追踪的矢量。格式为 Z 矩阵(FFF(I), I=1,NVAR),按 (8F10.6) 格式读取。

**MaxPoints=_N_**

沿反应路径考察的点数(若两个方向均需考虑,则每个方向各考察该数目)。默认值为 6。

**StepSize=_N_**

沿反应路径的步长,单位为 0.01 amu1/2-Bohr。默认值为 10。

**MaxCyc=_N_**

设定每次几何优化的最大步数。默认值为 20。

坐标系选择选项

**MassWeighted**

沿质量加权内坐标(Z 矩阵)追踪路径(这等价于沿质量加权笛卡尔坐标追踪路径)。MW 是 MassWeighted 的同义词。这是默认设置。

**Internal**

沿内坐标(Z 矩阵)追踪路径,不进行质量加权。

**Cartesian**

沿笛卡尔坐标追踪路径,不进行质量加权。

收敛相关选项

**VeryTight**

收紧路径上各点优化所用的收敛标准。若请求了非常小的路径步长,则必须使用此选项。

生成初始力常数的选项

**CalcFC**

指定在第一个点计算力常数。

**CalcAll**

指定在每个点都计算力常数。路径上每个优化点都会计算投影振动频率 [453]。注意,这些投影振动频率仅对在质量加权内坐标下计算的反应路径有效。

指定替代同位素

**ReadIsotopes**

该选项允许你指定与默认值不同的温度、压力、频率标度因子和/或同位素——默认分别为 298.15 K、1 个大气压、不进行标度,以及丰度最高的同位素。当希望使用与检查点文件中数据不同的参数重新分析时,此选项非常有用。但请注意,这些参数均可在路由段(Temperature、Pressure 和 Scale 关键字)及分子定义部分(Iso 参数)中指定,如下例所示:

```
#T Method /6-31G(d) JobType Temperature=300.0 ···
```

···

```
01
C(Iso=13)
```

···

ReadIsotopes 输入的格式如下:

*temp pressure [scale]数值必须为实数。* *原子 1 的同位素质量* *原子 2 的同位素质量* ··· *原子 n 的同位素质量*

其中 *temp*、*pressure* 分别为所需的温度和压力,*scale* 为用于热力学分析时频率数据的可选标度因子(默认不进行标度)。其余各行给出分子中各原子的同位素质量,顺序与分子定义部分中的出现顺序一致。若使用整数指定原子质量,程序将自动采用对应的精确同位素质量(例如,18 表示 18O,Gaussian 使用的值为 17.99916)。

重启选项

**Restart**

重启未完成的 IRCMax 计算,或重启已完成但需要沿路径获取额外点的 IRCMax 计算。

#### 5.48.2 可用性

IRC 部分的计算(上文的 *model1*)需要解析梯度。*model2* 可使用任何非复合能量方法和基组。

#### 5.48.3 相关关键字

IRC, Opt, Freq

#### 5.48.4 示例

以下计算将找到 HF/6-31G(d,p) 反应路径上 B3LYP/6-31G(d,p) 能量达到极大值的点:

```
#IRCMax(B3LYP/6-31G(d,p):HF/6-31G(d,p))
```

Zero 选项将生成零曲率变分过渡态理论(ZC-VTST)[509–512, 514, 517] 所需的数据。考虑以下路由段:

```
#IRCMax(MP2/6-311G(d):HF/6-31G(d),Zero,Stepsize=15,CalcAll)
```

该任务将从 HF/6-31G(d) 过渡态出发,沿 HF/6-31G(d) IRC 以 0.15 amu1/2Bohr 的步长搜索,直至 MP2/6-311G(d) 能量(包括 HF/6-31G(d) 零点能)的极大值被夹逼。随后将优化沿 HF/6-31G(d) IRC 上对应该 MP2/6-311G(d) 过渡态的位置。输出包括使用 ZC-VTST 版本绝对反应速率理论计算反应速率所需的全部量:过渡态转动惯量、所有实振动频率(HF/6-31G(d))、用于隧道效应的虚频(拟合至 MP2/6-311G(d) + ZPE),以及过渡态的总 MP2/6-311G(d) + ZPE 能量。注意,若未使用 CalcAll,则所有这些量(零点能、频率等)仅在 HF/6-31G(d) 水平计算,且同一组量将用于 IRCMax 路径上的所有点。
