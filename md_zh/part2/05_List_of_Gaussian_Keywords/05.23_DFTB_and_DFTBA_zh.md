### 5.23 DFTB 与 DFTBA

请求基于密度泛函的紧束缚半经验计算,该方法通过 DFT 计算结果进行参数化:

- DFTB 使用表格化矩阵元,与 Elstner 及其同事的原始实现相同 [333, 334]。
- DFTBA 是使用解析表达式而非表格化矩阵元的版本 [335]。综述与校准研究参见 [336–340]。

#### 5.23.1 选项

**Read**

从输入流中读取参数值。这是默认设置。

**ChkParameters**

从检查点文件中读取参数。

#### 5.23.2 可用性

能量、梯度和频率。当使用程序自带的解析 DFTB 参数时,可计算解析二阶导数;但使用 `dftb.org` 的表格参数时则不可用。这是因为使用表格参数进行的线性插值会在数据点处产生不连续的一阶导数,因此二阶导数并不总是存在。如果您希望忽略这一潜在问题,并使用表格参数计算二阶导数,则必须在作业的路由段中指定 Freq=Numer。

参数文件 DFTBA 对 H、C、N 和 O 的所有元素对均有参数化。它还对金属 Sc、Ti、Fe、Co 和 Ni 进行了参数化,但仅限与 H、C、N 和 O 配合使用。也就是说,支持 Fe5CO 和 Sc5CO,但不支持 Fe4ScCO。

DFTB 参数文件的版权归 Elstner 教授所有,须向其本人索取。

#### 5.23.3 示例

以下输入文件格式使用 Gaussian 提供的参数集运行 DFTBA 计算:

```
#DFTBAOPTFREQ
Ala3DFTBfrequencies
0,1
C,0,-4.5929012011,1.0163256276,1.6498020765
O,0,-5.6641782096,0.9622594116,2.2369288649
H,0,-5.788876035,3.2375262156,-2.1703220199
N,0,-4.4446298947,1.4038535552,0.3517633631
```

*分子规格继续* ···

```
@GAUSS_EXEDIR:dftba.prm
```

对于 DFTB,参数文件格式与其他程序相同:每对元素一个文件,且两个元素的顺序具有意义。因此,对 H2CO 进行计算时,参数输入段应类似如下:

```
@cc.prm
@oo.prm
@hh.prm
@co.prm
@oc.prm
@ch.prm
@hc.prm
@oh.prm
@ho.prm
```

能量在输出中显示如下:

```
SCFDone:E(RDFT-SCTBA)=-33.9465130617A.U.after11cycles
```

#### 5.23.4 修改 Slater-Koster 文件

DFTB 参数(.skf)文件与 Gaussian

为与 Elstner 提供的文件兼容,DFTB 输入文件的处理方式已作修改:文件末尾的 HTML 数据将被忽略。此外,现在可以接受乘数形式(例如 10*1.0)。

为 Gaussian 修改来自 dftb.org 的 Slater-Koster 文件(.skf)

每个文件的第一行必须编辑,以标明所涉及的两个元素。例如,在文件 *H-S.skf* 中,第一行应包含原子序数,因此需要将 dftb.org 格式:

```
2.000000000000E-02,500
```

改为 Gaussian 格式:

```
0.02, 500 1 16 Add atomic numbers for hydrogen and sulfur.
```

每个文件第一行的第二个字段,应为文件中包含哈密顿量和重叠积分网格点的行数。然而,这些数值通常只是占位符 500(如上)或 600。许多文件——尤其是较早的文件——实际提供的点数并非此值。若统计第一个点所在行与 `Spline` 之前最后一行之间的行数,即可得到所需的值:

```
2.000000000000E-02, 601 1 6 The next line is line 1.
0.000000000000E+000.000000000000E+000.000000000000E+000.000000000000E+00
0.000000000000E+000.000000000000E+000.000000000000E+000.000000000000E+00
-1.668269422592E-051.066481969438E-060.000000000000E+000.000000000000E+00
```

···

```
0.000000000000E+000.000000000000E+000.000000000000E+000.000000000000E+00
0.000000000000E+000.000000000000E+004.881740699644E-05-7.526317479277E-06
```

`Spline` *前一行是需要计数的最后一行。*

```
303.5
```

然后编辑第一行,以反映实际的点数:

```
0.02, 601 1 16 Some of the files involving hydrogens are links rather than separate files because they are
```

与其元素顺序颠倒的对应文件相同。例如,*H-C.skf* 是指向 *C-H.skf* 的链接。然而,Gaussian 要求两个文件都必须提供,二者仅在第一行的原子序数顺序上有所不同。
