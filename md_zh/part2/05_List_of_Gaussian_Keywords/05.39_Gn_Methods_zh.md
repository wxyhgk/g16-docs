### 5.39 Gn 方法(Gn 系列复合方法)

这些方法关键字用于请求以下计算高精度能量的方法:

- Gaussian-1 (G1) [462, 463]
- Gaussian-2 (G2) [464]
- Gaussian-3 (G3) [465]
- Gaussian-4 (G4) [466]
- G2MP2 用于请求 G2 的改进版本,即 G2(MP2),它在基组扩展修正中使用 MP2 代替 MP4 [467],在大幅降低计算成本的同时,精度与完整的 G2 方法几乎相当。
- G3MP2 用于请求类似改进的 G3(MP2) 方法 [468]。
- 使用 B3LYP 结构和频率的 G3 变体 [469] 通过 G3B3 和 G3MP2B3 关键字请求。
- G4 和 G4MP2 用于请求第四代方法 [466, 470]。所有这些方法都是复杂的能量计算,涉及对指定分子体系进行若干预定义的计算。指定这些关键字后,所有不同步骤都会自动执行,最终计算得到的能量值将显示在输出中。使用这些关键字时不应指定基组关键字。在选择这些方法之前,用户通常应考虑其他高精度方法:CBS-QB3 同样精确但速度明显更快,而 W1U 精度更高(但速度更慢)。Opt=Maxcyc=*n*、QCISD=Maxcyc=*n* 或 CCSD=Maxcyc=*n* 关键字中的任一个都可与上述任何关键字联用,分别用于指定最大优化循环数、QCISD 循环数或 CCSD 循环数。

#### 5.39.1 选项

**SP**

仅使用指定的复合模型化学方法进行单点能量计算。不包含零点能或热能。

**NoOpt**

在输入几何结构上对指定模型化学方法进行频率计算和单点能量计算。隐含 Freq=TProjected。对于 G1 等在频率计算和单点计算步骤中使用不同几何结构的方法,此选项没有意义,也不被接受。StartFreq 是 NoOpt 的同义词。

**ReadIsotopes**

该选项允许你指定替代的默认温度、压力、频率缩放因子和/或同位素——默认值分别为 298.15 K、1 个大气压、不缩放以及最丰富的同位素。当你希望使用与检查点文件中数据不同的参数重新运行分析时,此选项非常有用。但请注意,所有这些参数都可以在路由段中指定(Temperature、Pressure 和 Scale 关键字),也可以在分子描述部分中指定(Iso 参数),例如以下示例:

```

```

ReadIsotopes 输入的格式如下:

*temp pressure [scale]* 数值必须为实数。 *原子 1 的同位素质量* *原子 2 的同位素质量* ··· *原子 n 的同位素质量*

其中,*temp*、*pressure* 和 *scale* 分别为所需的温度、压力,以及用于热化学分析时频率数据的可选缩放因子(默认不缩放)。其余各行给出分子中各原子的同位素质量,顺序与分子描述部分中出现的顺序相同。若使用整数指定原子质量,程序将自动采用对应的实际精确同位素质量(例如,18 表示 18O,Gaussian 使用的数值为 17.99916)。

**Restart**

从检查点文件中恢复部分完成的计算。与 ReadIso 联用时,此选项可快速计算使用不同热化学参数和/或同位素选择时的能量。

#### 5.39.2 示例

**计算摘要输出。** 在所有作业子步骤的输出之后,Gaussian 会打印这些方法的结果表。以下是一次 G2 计算的输出:

```
Temperature=298.150000Pressure=1.000000
E(ZPE)=.020511E(Thermal)=.023346
E(QCISD(T))=-76.276078E(Empiric)=-.024560
DE(Plus)=-.010827DE(2DF)=-.037385
G1(0K)=-76.328339G1Energy=-76.325503
G1Enthalpy=-76.324559G1FreeEnergy=-76.303182
E(Delta-G2)=-.008275E(G2-Empiric)=.004560
G2(0K)=-76.332054G2Energy=-76.329219
G2Enthalpy=-76.328274G2FreeEnergy=-76.306897
```

首先输出温度和压力,随后是用于计算 G2 能量的各个分量。输出以 0 K 时的 G2 能量以及指定温度下的 G2 能量结束(后者包含完整的热修正,而不仅仅是零点能修正),并在最后一行给出 G2 理论对焓和吉布斯自由能的预测值(两者均使用经热修正的 G2 能量计算)。(注意,此摘要部分同样会打印 G1 水平的相应数值。)因此,能量标签的含义如下(以 G2 为例):

*G2 (0 K)* 零点修正后的电子能量:E0 = E*elec* + ZPE *G2 Energy* 热修正能量:E = E0 + E*trans* + E*rot* + E*vib* *G2 Enthalpy* 使用 G2 预测能量计算的焓:H = E + RT *G2 Free Energy* 使用 G2 预测能量计算的吉布斯自由能:G = H - TS
