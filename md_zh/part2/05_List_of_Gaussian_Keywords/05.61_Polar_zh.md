### 5.61 Polar(极化率)

此方法关键字要求计算偶极电场极化率(以及在可能情况下计算超极化率)。不隐含几何结构变化或导数计算,但该关键字可以与在路由段中同时指定 Freq 和 Polar 所进行的力数值微分结合在同一作业中。对于缺少解析梯度的方法(MP4(SDTQ)、QCISD(T)、CCSD(T) 等),Freq 与 Polar *不能*组合使用。注意,当二阶导数为解析计算时,默认会进行 Polar 计算。极化率与超极化率在输出中分别以标准取向下的下三角与下四面体顺序给出:α *xx*、α *xy*、α *yy*、α *xz*、α *yz*、α *zz*,以及 β *xxx*、β *xxy*、β *xyy*、β *yyy*、β *xxz*、β *xyz*、β *yyz*、β *xzz*、β *yzz*、β *zzz*。通常情况下,极化率与超极化率采用静态频率计算。然而,若在路由段中包含 CPHF=RdFreq 并在输入文件中指定所需频率,则可以计算频率依赖的极化率与超极化率(文献 [611–615])。也可以通过 OptRot 选项预测旋光度(文献 [396, 626–633])。应用示例参见文献 [634–636]。

拉曼光谱与 ROA 光谱的预测:拉曼强度与 ROA 强度可以与力常数及简正模式的计算分开进行,以便如文献 [401] 所推荐的那样,使用更大的基组计算这些性质。选项 Polar=Raman 和 Polar=ROA 要求从检查点文件中读取力常数(即来自先前的 Freq 计算),并计算新的极化率导数(对于 ROA 还需计算另外两个张量导数),然后将其与力常数结合以预测强度与光谱。测试作业 *931* 给出了两步 ROA 计算的示例。对于这类作业,请注意:日志文件存档条目以及最终检查点文件/格式化检查点文件中报告的能量,是频率作业中计算得到的能量——即作业开始时从检查点文件读取的数值——而不是在拉曼/ROA 计算所用模型化学中计算并在最终 `SCF Done` 输出行中报告的能量。

#### 5.61.1 选项

**ROA**

使用 GIAO 计算动态解析拉曼光学活性强度(文献 [401])。此过程需要在输入中提供一个或多个入射光频率,用于电磁微扰(对于 Freq=ROA,默认使用 CPHF=RdFreq)。示例参见"示例"部分。此选项适用于 Hartree-Fock 和 DFT 方法。

**Raman**

根据从检查点文件中读入的力常数计算拉曼光谱。

**OptRot**

进行旋光度计算。使用 CPHF=RdFreq 指定所需频率。仅适用于 HF 和 DFT。此选项不能与 NMR 组合使用。若要计算完整的旋光张量(文献 [399, 627]),请在路由段中包含 IOp(10/46=7),以计入偶极-磁偶极极化率中的偶极-四极贡献;此时该张量在输出中将被标记为

```
Optical Rotation G’ tensor in the output. Note that doing so does not change the optical
```

旋光度的数值不因此改变。

**DCSHG**

为 dc-SHG(直流二次谐波产生)超极化率进行额外的频率依赖 CPHF 计算。此选项同时隐含 CPHF=RdFreq。

**Gamma**

等价于 Polar=(DCSHG,Cubic),用于计算二阶超极化率。

**Analytic**

在具有解析三阶导数时,解析计算极化率与超极化率。对于具有解析二阶导数的方法(RHF 和 UHF、CASSCF、CIS、MP2 以及 DFT 方法),此选项为默认选项。注意,在解析频率计算中始终会计算极化率。

**WorkerPerturbations**

在使用 Linda 并行的数值频率计算中,在各个工作节点上分别运行不同的位移,而不是将每次能量加导数的计算并行分布到整个集群上。效率更高,但需要在主节点上额外指定一个工作节点。若指定了至少 3 个 Linda 工作节点,则此为默认行为。NoWorkerPerturbations 可取消此行为。

**FourPoint**

在数值频率、极化率或 freq=anharm 计算中,对每个自由度进行四次位移而非两次。这样可获得更高的精度,并降低对步长的敏感性,但计算量加倍。

**DoubleNumer**

对于具有解析梯度(一阶导数)的方法,计算超极化率以及极化率。对于没有解析导数的方法,通过对能量进行双重数值微分来计算极化率。EnOnly 是 DoubleNumer 的同义词。

**Cubic**

对解析极化率进行数值微分以得到超极化率。仅适用于具有解析频率但没有解析三阶导数的方法。

**Numerical**

将极化率计算为偶极矩的数值导数(当然,它是能量的解析导数,而非 MP2 或 CI 能量情形下的期望值)。对于仅具有解析一阶导数梯度的方法,这是默认选项。

**Step=_N_**

将电场中的步长指定为 0.0001 *N* 原子单位(适用于数值微分)。

**Restart**

从检查点文件重新开始 *数值* 计算。失败的 Polar 计算可以通过重复原作业的路由段并在 Polar 关键字中添加 Restart 选项,从其检查点文件重新开始。无需其他输入。

**Susceptibility**

计算磁化率以及其他性质(参见 NMR)。仅适用于 HF 和 DFT。

**TwoPoint**

在计算数值导数时,对每个坐标进行两次位移。这是默认设置。FourPoint 将进行四次位移,但仅适用于 Link 106(Polar=Numer)。不适用于 Polar=DoubleNumer。

**Dipole**

计算偶极极化率(默认)。

#### 5.61.2 可用性

下表总结了计算各可用方法的极化率与超极化率所需的 Polar 选项。

**方法能力  极化率  超极化率**

解析三阶导数(HF、大多数 DFT)  Polar(*默认*=Analytic)  Polar(*默认*=Analytic)
解析频率(MP2、CIS、···)  Polar(*默认*=Analytic)  Polar=Cubic
仅有解析梯度(CCSD、BD、···)  Polar(*默认*=Numeric)  Polar=DoubleNumer
无解析导数(CCSD(T)、···)  Polar(*默认*=DoubleNumer)  不适用

频率依赖的极化率与超极化率(即 Polar CPHF=RdFreq)仅适用于 HF 和 DFT 方法。

#### 5.61.3 相关关键字

Freq、CPHF=RdFreq
