### 5.18 Counterpoise(counterpoise 校正)

可以使用 Counterpoise 关键字计算 counterpoise 校正 [212, 213]。该关键字可用于能量计算、几何优化、频率计算或 BOMD 计算。Counterpoise 关键字需要一个整数值,指定分子结构中的片段或单体数目,例如 Counterpoise=2。我们推荐使用定义片段的新语法(参见分子规范概述),示例中即采用该语法。《*Exploring Chemistry with Electronic Structure Methods*》第 9 章 [152, 第 440、442–44、454–56 页] 概述了 counterpoise 校正,并包含若干示例。

#### 5.18.1 选项

**NewGhost**

请求新式鬼原子(ghost atom),其 DFT 积分格点同样包括在内。NewBq 为 NewGhost 的同义词。这是默认且推荐的方法。

**OldGhost**

请求旧式鬼原子。OldBq 为 OldGhost 的同义词。此选项仅用于与以前的结果进行比较。

#### 5.18.2 可用性

不能与 ONIOM 或 SCRF 一起使用。Counterpoise 计算无法生成分子轨道。

#### 5.18.3 示例

**Counterpoise 输入。** 以下输入是 counterpoise 计算的一个示例:

```
#UB3LYP/6-31G(d)Counterpoise=2
Counterpoiseonwaterdimer
1,21,20,1
O(Fragment=1)0.000.000.00
O(Fragment=2)0.000.002.98
H(Fragment=1)0.490.76-0.29
H(Fragment=1)0.49-0.76-0.29
H(Fragment=2)-0.910.003.24
H(Fragment=2)-0.010.002.03
```

上述作业还展示了片段特定的电荷和自旋多重度设定方式。电荷与自旋行中的第一对数值给出整个分子的值;随后依片段编号顺序给出每个片段的电荷和自旋。以下是使用 ECP 的 counterpoise 几何优化示例:

```
#B3LYP/LANL2DZCounterpoise=2NoSymmOpt
HBr+HF,optimizationwithcounterpoisecorrectionusingECPbasis
010101
H(Fragment=1)0.000000000.000000000.58022808
Br(Fragment=1)0.000000000.00000000-0.83659185
F(Fragment=2)0.000000000.000000002.77788358
H(Fragment=2)0.000000000.000000003.69953441
```

**Counterpoise 输出。** Counterpoise 计算的典型输出如下:

```
Counterpoisecorrectedenergy=-622.483714884838
BSSEenergy=0.005664641553
sumoffragments=-622.333463706103
complexationenergy=-97.84kcal/mole(raw)
complexationenergy=-94.28kcal/mole(corrected)
```

这些行分别给出 counterpoise 校正能量以及基组叠加误差(BSSE)。
