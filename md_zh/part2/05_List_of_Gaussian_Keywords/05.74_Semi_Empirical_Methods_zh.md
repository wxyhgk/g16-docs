### 5.74 半经验方法

Gaussian 16 提供多种半经验方法。AM1 和 PM3 方法已在标准积分处理基础设施上重新实现 [725–727](而非使用公有领域的 MOPAC 代码)。除了效率提高外,这一改动还提供了解析梯度和频率。PM6 和 PDDG 也以这种方式实现。其余半经验方法使用 Link 402 中修改版的 MOPAC,它们在各自的页面中讨论。

- AM1: 使用 AM1 哈密顿量请求半经验计算 [519, 521, 522, 527, 728–734]。
- PM3: 使用 PM3 哈密顿量请求半经验计算 [735, 736]。Li 的参数已按 [734] 中的说明更新。PM3MM 指定包含 HCON 连接可选分子力学修正的 PM3 模型。
- PM6: 使用 PM6 哈密顿量请求半经验计算 [737]。也可使用 PDDG 变体 [340, 738–741]。
- PM7: 使用经 Throssel 和 Frisch 修改、用于连续势能面的 PM7 哈密顿量请求半经验计算 [742]。PM7R6 为其同义词。Stewart 的原始 PM7 方法 [743] 可通过 PM7MOPAC 关键字请求。

除非指定 NoGenerate 选项,程序会自动生成支持原子的标准参数。也可以通过多种方式读入附加和/或替代参数(参见*选项*)。两者同时使用时,读入的参数优先于内部参数。

对含第三周期及更高周期元素的体系使用 PM7

对于含有这些元素的某些体系,PM7 波函数中可能存在不稳定性,波函数可能难以收敛。这在较轻元素中较少见,在过渡金属配合物中最常发生。在这种情况下,首先应尝试替代的 SCF 算法,例如 SCF=YQC。若仍失败,可以采用其他方法,如使用不同的初始猜测,或从使用其他方法的计算中读入密度(参见 Guess 关键字)。

在某些情况下,找到的 PM7 波函数可能不是最低能量的 SCF 解。这一点在过渡金属中也最常见,因此对过渡金属进行计算时需谨慎。检验波函数的一个直接方法是使用 Stable 关键字。

#### 5.74.1 选项

**Generate**

为指定方法生成标准参数。这是默认值。NoGenerate 表示不生成任何标准参数;所有参数都必须读入。

**Input**

从输入流中以 Gaussian 格式读入参数。可以指定或覆盖任何参数。输入段必须以空行结束。Cards 是 Input 的同义词。

**MOPACExternal**

从输入流中以 MOPAC 的外部格式和单位读入参数。大多数(但并非全部)参数可以更改。输入段必须以空行结束。

**Both**

从输入流中读入参数,先以 Gaussian 格式读入,然后以 MOPAC 格式读入更多参数。两个输入段都必须以空行结束。

**Checkpoint**

从检查点文件中读入参数。Chk 和 Read 与 Checkpoint 同义。

**TCheckpoint**

若检查点文件中存在参数,则从中读入;否则生成参数。

**RWF**

从读写文件中读入参数。

**Print**

以 Gaussian 格式打印当前作业中各元素所用的参数。若从输入文件读入参数,这是默认值。NoPrint 表示不打印参数,若使用标准参数,则这是默认值。

**PrintAll**

以 Gaussian 格式打印所有元素的参数(即使它们不在分子定义中)。

**Zero**

打印所有参数,包括值为零的参数。默认为 NonZero,即只打印非零参数。

**Old**

使用旧的基于 MOPAC 的代码。二阶导数通过数值方法计算。仅适用于 AM1 和 PM3。默认为 New,即使用上面所述的新实现。

#### 5.74.3 可用性

能量、优化和频率计算。程序中已为以下元素存储了参数:

- AM1: H、Li-F、Mg-Cl、Cr、Zn、Ge、Br、Sn、I 和 Hg。
- PM3: H、Li-F、Na-Cl、K、Ca、Cr、Zn-Br、Rb、Sr、Cd-I、Cs、Ba 和 Hg-Bi。
- PM6: H-Ba 和 Lu-Bi。
- PM7: H-La 和 Lu-Bi。

#### 5.74.4 相关关键字

CNDO、INDO、MNDO、MINDO3
