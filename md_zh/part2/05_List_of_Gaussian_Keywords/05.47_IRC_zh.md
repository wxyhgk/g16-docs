### 5.47 IRC(固有反应坐标)

本计算类型关键字请求通过对固有反应坐标积分来追踪反应路径 [501, 502]。初始几何结构(在分子规格段中给出)为过渡态的结构,路径可从该点沿一个或两个方向追踪。*正向*定义为过渡向量最大分量("相位")为正时过渡向量所指的方向;可以使用 Phase 选项显式定义。默认情况下,两个反应路径方向都会被追踪。IRC 计算*需要*初始力常数才能进行。必须以某种方式为计算提供这些力常数。通常的方法是保存前面频率计算的检查点文件(用于验证将用于 IRC 计算的优化几何结构确实是过渡态),然后在路由段中指定 RCFC 选项。另一种可能是在 IRC 计算开始时计算它们(CalcFC)。注意,必须指定 RCFC 和 CalcFC 之一(CalcAll 也可用,但在 HPC 算法中通常不必要)。在 Gaussian 16 中,大多数计算默认使用 HPC 算法 [502–504](Gaussian 09 中引入)。它比早期程序版本所用的算法效率高得多。ONIOM(MO:MM) 计算使用欧拉预测-校正积分算法。对于具有梯度但不具有解析二阶导数的方法,此同一积分器也是默认使用的;此类计算应包含 GradientOnly 选项。可用算法在*可用性*中讨论。

默认情况下,仅报告路径上每个点的能量和反应坐标;如果需要沿路径的几何参数,应通过 Geom=ModRedundant 将其定义为冗余内坐标,或通过 IRC(Report=Read) 作为 IRC 代码的输入(后者的输入格式见*选项*)。可以使用 ReadIsotopes 选项(在*选项*中描述)为 IRC 作业指定替代同位素。

#### 5.47.1 选项

路径指定选项

**Phase=(_N1_, _N2_ [,_N3_ [,_N4_]])**

定义过渡向量的相位,使得沿过渡向量的正向运动对应于指定内坐标的增加,该内坐标由至多四个原子编号指定。若给出两个原子编号,则该坐标为两原子之间的键伸缩;三个原子编号指定键角弯曲;四个原子定义二面角。

**Forward**

仅沿正向追踪路径。

**Reverse**

仅沿反向追踪路径。

**Downhill**

从输入几何结构开始沿下坡方向前进。

**MaxPoints=_N_**

沿反应路径检查的点数(若两个方向都考虑,则每个方向各为此数)。默认值为 10。

**StepSize=_N_**

沿反应路径的步长,单位为 0.01 玻尔。若 *N*<0,则步长以 0.01 amu^1/2·玻尔为单位。默认值为 10。

**ReadIsotopes**

该选项允许您指定与默认温度、压力、频率标度因子和/或同位素(分别为 298.15 K、1 个大气压、无标度和最丰富同位素)不同的替代值。当您希望使用检查点文件中的数据、以不同参数重新运行分析时,此选项很有用。但请注意,所有这些参数都可以在路由段(Temperature、Pressure 和 Scale 关键字)以及分子规格段(Iso 参数)中指定,如以下示例所示:

```
#T Method /6-31G(d) JobType Temperature=300.0 ···
```

···

```

```

···

ReadIsotopes 输入具有以下格式:

*temp pressure [scale]数值必须为实数。* *原子 1 的同位素质量*

*原子 2 的同位素质量* ··· *原子 n 的同位素质量*

其中 *temp*、*pressure* 和 *scale* 分别为所需的温度、压力,以及用于热化学分析时频率数据的可选标度因子(默认为未标度)。其余各行给出分子中各原子的同位素质量,顺序与分子规格段中出现的顺序相同。如果使用整数指定原子质量,程序将自动使用相应的实际精确同位素质量(例如,18 表示 18O,Gaussian 使用值 17.99916)。

算法选择选项

**HPC**

使用基于 Hessian 的预测-校正积分器 [502–504]:这是一种非常精确的算法,使用基于 Hessian 的局部二次近似作为预测器部分,并使用修改的 Bulirsch-Stoer 积分器作为校正器部分。该校正积分器使用距离加权插值曲面 [505] 完成,该曲面拟合于预测步起点和终点处的能量、梯度和 Hessian。这是大多数计算的默认设置。注意,对于极大的分子体系,它不实用。

**EulerPC**

预测步使用一阶欧拉积分,并与 HPC 校正步组合。这是 IRC=GradientOnly 计算的默认设置。这也是 ONIOM(MO:MM) 方法 IRC 计算的默认算法。对于此类大分子计算,这是一种实用的选择。

**LQA**

预测步使用局部二次近似 [406, 409]。

**DVV**

使用阻尼速度 Verlet 积分器 [506]。

**Euler**

IRC 的预测步仅使用一阶欧拉积分。不推荐用于生产计算。

**ReCalc=_N_**

每 *N* 个预测步解析计算一次 Hessian;若 *N*<0,则每 |*N*| 个校正步计算一次。可以在 IRC 期间使用 IRC=(CalcFC,RecalcFC=(Predictor=*N*, Corrector=*M*)) 间歇地请求解析二阶导数,该设置在初始点计算二阶导数,然后每第 *N* 个预测步和每第 *M* 个校正步计算二阶导数。您仍必须指定 RCFC 或 CalcFC 以提供初始 Hessian。Update 是 ReCalc 的同义词。需要具有解析二阶导数的方法。

**GradientOnly**

使用不需要二阶导数的算法。注意,对于此类方法(它们不会被自动检测),必须显式指定此选项。可与 EulerPC(默认)、HPC、Euler 或 DVV 组合使用。

坐标系选择选项

**MassWeighted**

沿质量加权笛卡尔坐标追踪路径。MW 是 MassWeighted 的同义词。这是默认设置。

**Cartesian**

沿笛卡尔坐标追踪路径,不进行质量加权。

生成初始力常数的选项

**RCFC**

指定从频率计算中得到的笛卡尔坐标力常数从检查点文件中读取。ReadCartesianFC 是 RCFC 的同义词。

**CalcFC**

指定在第一个点计算力常数。

流程相关选项

**Restart**

重启未完成的 IRC 计算,或重启已完成但需要沿路径获取更多点的 IRC 计算。

**Report[=_item_]**

控制 IRC 报告哪些几何参数。默认情况下,不报告任何几何参数。不带参数的 Report 会包括所有生成的内坐标。*item* 的可能取值为:Read,读取要报告的内坐标列表。这些坐标仅以 1-4 个原子编号指定(不支持 ModRedundant 风格的坐标规格)。Bonds,报告内坐标中的键(若存在)。Angles,报告内坐标中的键角(若存在)。Dihedrals,报告内坐标中的二面角(若存在)。Cartesians,报告所有笛卡尔坐标。

**ReCorrect[=_when_]**

控制 HPC 和 EulerPC IRC 校正步的测试与重算。ReCorrect(不带参数)和 ReCorrect=Yes 表示每当校正量大于阈值(可通过 Tight 和 VTight 选项降低)时重复校正步。该参数可取以下值:

Never 不重复校正步(即抑制阈值测试)。Always 无论初始校正大小如何,至少重新计算一次校正器。Test 测试校正步的质量并报告结果,但不进行额外的校正步。计算得到的 IRC 路径将与 ReCorrect=Never 时相同。

默认值对 EulerPC 和 HPC 为 Yes,对其他积分器为 Never。

**MaxCycle=_N_**

将最大步数设为 *N*。默认值为 20。

**Tight**

该选项收紧用于判断收敛的力和步长判据。对于 DFT 计算,还应指定 Int=UltraFine。

**VeryTight**

极其严格的优化收敛判据。VTight 是 VeryTight 的同义词。对于 DFT 计算,还应指定 Int=UltraFine。

与 Gaussian 03 兼容的选项:GS2 选项请求在新 IRC 实现中使用 Gaussian 03 所用的 IRC 算法。若要运行 Gaussian 03 中的默认代码(仅建议用于重现旧结果),请使用关键字 Use=L115。

**GS2**

使用 Gaussian 03 及更早版本中的默认 IRC 算法 [507, 508]。在反应路径的每个点处优化几何结构,使得任意两个相邻点之间的路径段由圆弧描述,且圆弧端点处的梯度与路径相切。默认情况下,GS2 IRC 计算在质量加权内坐标中沿正向取 6 个点、沿反向取 6 个点,步长为沿路径 0.1 amu^1/2·玻尔。

**CalcAll**

指定在每个点都计算力常数。

#### 5.47.2 可用性

默认算法可用于 HF、所有 DFT 方法、CIS、TD、MP2、MP3、MP4(SDQ)、CID、CISD、CCD、CCSD、QCISD、BD、CASSCF 以及所有半经验方法。
