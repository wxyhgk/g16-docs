### 5.3 ADMP(原子中心密度矩阵传播)

本关键字请求使用原子中心密度矩阵传播(Atom Centered Density Matrix Propagation)分子动力学模型进行经典轨迹计算 [120–123]、[124–126]。该方法在显著降低计算成本的同时,提供与玻恩-奥本海默分子动力学(BOMD)(参见 BOMD 关键字)等效的功能 [126]。ADMP 属于使用高斯基函数并传播密度矩阵的扩展拉格朗日分子动力学方法。该类方法中最著名的是 Car-Parrinello(CP)分子动力学 [127],其中以 Kohn-Sham 分子轨道 ψ *i* 作为动力学变量来描述体系的电子自由度。CP 计算通常在平面波基组中进行(有时也会加入高斯轨道作为辅助 [128–130])。与平面波 CP 不同,ADMP 不需要对氢原子使用赝势,也不需要用氘代替氢来进行动力学模拟。电子自由度的虚拟质量由程序自动设定 [126],且可以足够小,使得无需恒温器即可获得良好的能量守恒。ADMP 可用于半经验方法、HF 以及纯 DFT 和杂化 DFT 模型(详见 *可用性* 页签)。它可应用于分子、团簇和周期性体系。PBC 计算仅使用 Γ 点(即不进行 K 点积分)。

#### 5.3.1 输入

虽然多数计算不需要额外输入,ADMP 计算仍可接受一些输入。下面第一节给出 ReadVelocity 和 ReadMWVelocity 选项所用的可选初始笛卡尔速度。

*原子 1 的初始速度: x y z(可选的初始笛卡尔速度)* *原子 2 的初始速度: x y z(ReadVelocity 和 ReadMWVelocity 选项)* ··· *原子 N 的初始速度: x y z* ···

首先,若包含 ReadVelocity 或 ReadMWVelocity 选项,则读取每个原子的初始速度。每个初始速度分别以原子单位(玻尔/秒)表示的笛卡尔速度,或以质量加权笛卡尔速度(amu^1/2·玻尔/秒)表示。每个请求的轨迹计算需读取一整套速度。若存在该信息,其后可紧接(不留空行)每个双原子产物的 Morse 参数:

*原子1, 原子2, E0, Len, De, Be* ··· *轨迹输入子部分须以空行结束。*

Morse 参数数据用于借助 EBK 量子化规则确定双原子碎片的振动激发。它包括两个原子的元素符号、两原子间的键长(Len,单位为埃)、该距离处的能量(E0,单位为哈特里)以及 Morse 势曲线参数 De(哈特里)和 Be(埃⁻¹)。该输入子部分以空行结束。

#### 5.3.2 选项

**MaxPoints=_n_**

指定每条轨迹中允许的最大步数(默认为 50)。若重启轨迹计算,最大步数将默认为原始计算中指定的值。

**Lowdin**

使用 Löwdin 基作为正交基。另一种选择是 Cholesky 基,为默认值。

**NKE=_N_**

将初始核动能设为 *N* 微哈特里。NuclearKineticEnergy 是该选项的同义词。默认值为 100000(相当于 0.1 哈特里)。

**DKE=_N_**

将初始密度动能设为 *N* 微哈特里。DensityKineticEnergy 是该选项的同义词。

**ElectronMass=_N_**

将虚拟电子质量设为 |*N*/10000| amu(默认 *N*=1000,对应虚拟质量 0.1 amu)。EMass 是该选项的同义词。若 *N*<0,则对所有基函数采用均匀缩放。默认情况下,内层基函数的权重大于价层基函数。

**FullSCF**

在每个点都以收敛的 SCF 结果进行动力学计算。

**ReadVelocity**

从输入流中读取初始笛卡尔速度。注意速度必须与分子具有相同的对称取向。该选项会抑制五阶非谐性修正。

**ReadMWVelocity**

从输入流中读取初始质量加权笛卡尔速度。注意速度必须与分子具有相同的对称取向。该选项会抑制五阶非谐性修正。

**StepSize=_n_**

将动力学步长设为 *n* × 0.0001 飞秒。默认值为 1000(步长 0.1 飞秒)。

**BandGap**

是否对 Fock 矩阵进行对角化,以便在每一步报告能隙。默认为 NoBandGap。

**Restart**

从检查点文件重启 ADMP 计算。注意原始计算中设置的选项仍然有效,且无法修改。

**ReadIsotopes**

该选项允许你指定替代默认值的温度、压力、频率缩放因子和/或同位素——默认值分别为 298.15 K、1 个大气压、不缩放以及丰度最高的同位素。当你希望使用不同于检查点文件中数据的参数重新进行分析时,该选项很有用。但请注意,上述所有参数均可在路由段(Temperature、Pressure 和 Scale 关键字)以及分子说明部分(Iso 参数)中指定,例如:

```
#T Method /6-31G(d) JobType Temperature=300.0 ···
```

ReadIsotopes 输入格式如下:

*temp pressure [scale]数值必须为实数。* *原子 1 的同位素质量* *原子 2 的同位素质量* ··· *原子 n 的同位素质量*

其中 *temp*、*pressure* 和 *scale* 分别为所需温度、压力以及可选的频率数据缩放因子(用于热化学分析,默认不缩放)。其余各行给出分子中各原子的同位素质量,顺序与分子说明部分中的排列顺序一致。若用整数指定原子质量,程序将自动使用对应的精确同位素质量(例如,18 表示 ¹⁸O,Gaussian 采用值 17.99916)。
