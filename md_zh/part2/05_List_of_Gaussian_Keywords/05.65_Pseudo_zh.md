### 5.65 Pseudo(赝势)

该关键字请求用模型势替代内层(芯)电子。Cards 选项是迄今最常用的模式。Gaussian 支持新的有效核势(ECP,effective core potential)输入格式(与 ExtraBasis 所用格式相似),详见"格式"标签页。读入赝势时,不要使用与内部存储赝势相同的名称:CEP、CHF、LANL1、LANL2、LP-31、SDD 和 SHC。若与 ONIOM 一起使用,Pseudo 关键字适用于 ONIOM 的所有层。若只想为某一 ONIOM 层读入 ECP,则应改用 GenECP 关键字。不带任何选项时,该关键字默认为 Pseudo=Read。

#### 5.65.1 选项

**Read**

从输入流中读取赝势数据。输入格式见下一小节。Cards 是 Read 的同义词。

**SOScal**

使用 Pseudo=Read 从输入读入赝势时,按照已发表的 CRENBL 赝势的要求,将自旋轨道系数(若存在)乘以 2/L 进行缩放。默认不进行缩放,这适用于 Dolg(斯图加特)赝势。

**CHF**

请求使用无芯 Hartree-Fock 赝势。该选项通常与 LP-31G 基组一同使用。

**SHC**

请求使用 SHC 赝势。

**LANL1**

请求使用 LANL1 赝势。

**LANL2**

请求使用 LANL2 赝势。

**Old**

使用旧格式读取赝势数据(Gaussian 92 及更早版本所用的格式)。

#### 5.65.2 格式

完整 ECP 输入格式

有效核势算符是多项式径向函数、高斯径向函数与角动量投影算符乘积之和。因此,ECP 输入需指定每个原子中心使用哪种势,然后为每种势的每个角动量项给出一组三元组:*(系数, R 的幂次, 指数)*。由于只有前几个角动量分量包含不同的项,势被表示为(1)通用情形的项,通常为 d 或更高的投影,以及(2)每个特殊角动量的附加项。因此,对于包含特殊 s 和 p 投影项的 LP-31G 势,输入包括通用(d 及更高)项、s-d 项(即为使通用项成为 s 分量需要添加的内容)以及 p-d 项。所有 ECP 输入均为自由格式。每个块以一行开始,该行给出中心编号(来自分子规格说明)和/或原子符号,指明其适用的原子和/或原子类型(与通用基组输入相同,参见 Gen 关键字的讨论)。列表以值 0 结束。随后给出这些中心/原子的赝势:

**_Name,Max,ICore_**

势的名称、势的最大角动量(即若有特殊 s 和 p 投影则为 2,若有 s、p 和 d 投影则为 3),以及被该势替代的芯电子数。若 *Name* 与之前某个势的名称相同,则复用该势,除终止行外不需要其他输入。对于当前势的每个分量(*I*=1 至 *Max*),读入一组项,包含以下信息:

**_Title_**

块的说明,不作其他用途。

**_NTerm_**

块中的项数。

**_NPower,Expon,Coeff[,SO]_**

*NTerm* 个项中每一项的 R 的幂次、指数和系数。*NPower* 包括 R 的 2 次雅可比因子。可选的 SO 系数用于包含该项的 ECP 基组。

简化 ECP 输入格式 Gaussian 允许 ECP 输入包含预定义的基组名称,从而增加了灵活性。ECP 定义可以替换为一行,其中包含预定义基组的标准关键字。在这种情况下,该基组中对应于指定原子类型的 ECP 将用于该原子(参见示例)。

#### 5.65.3 关键字

在 Pseudo 输入中,这些 ECP 的关键字形式为 *XYn*,其中 *n* 是被赝势替代的芯电子数,*X* 表示生成赝势所用的参考体系(S 表示单价电子离子,M 表示中性原子)。*Y* 指定参考数据的理论水平:HF 表示 Hartree-Fock,WB 表示 Wood-Boring 准相对论,DF 表示 Dirac-Fock 相对论。对于单价或双价电子原子,SDF 是一个好的选择;否则推荐 MWB 或 MDF(不过对于小原子或考虑相对论效应时,相应的 SHF 和 MHF 赝势可能有用)。
