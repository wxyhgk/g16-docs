### 5.27 External(外部程序)

请求使用外部程序进行计算。该机制主要用于借助外部程序完成 ONIOM 计算中的低层计算,但也可以用于借助外部程序提供函数值与导数,并使用 Gaussian 的优化器进行几何优化。Gaussian 使用标准化接口,在每个几何结构上运行外部程序以得到能量(以及可选的偶极矩或力)。程序会生成一个包含当前结构的文本文件,并默认运行名为 *Gau_External* 的脚本(指定其他脚本的方法见下文)。该脚本由用户提供,预期完成以下工作:

- 将文本文件(称为"输入文件")转换为另一程序的输入。
- 运行该程序。
- 将结果转换为 Gaussian 可以读取的标准文本格式。供 Gaussian 使用的转换后文件称为"输出文件"。您可以通过在 External 关键字后添加脚本名作为选项来指定其他脚本,例如:External=MyScript。

#### 5.27.1 脚本调用

默认情况下,*Gau_External* 脚本接收六个参数:

**$ Gau_External** *layer InputFile OutputFile MsgFile FChkFile MatElFile*

各参数的定义如下:

*layer* 一个关键字母,指示计算是针对真实体系(R)、两层 ONIOM 的模型体系或三层 ONIOM 的中间层(M)、还是三层 ONIOM 的模型体系(S)进行的。*InputFile* Gaussian 为外部程序准备的输入文件名。*OutputFile* 外部程序运行结束后需要读取的文件名。*MsgFile* 用于存放消息的文件名;若脚本创建了该文件,则其内容会被复制到 Gaussian 输出文件中。*FChkFile* 格式化检查点文件。若相应选项设置为 link 402,则在启动外部脚本之前会从读写文件中创建此文件,脚本结束后可以读取该文件以导入结果,而不必通过 *OutputFile* 提供 Gaussian 输入。输出的格式化检查点文件可以包含开头的两个空行,加上按常规格式更新的数据;它无需包含保持不变的任何信息。*MatElFile* 矩阵元文件。这是一个 Fortran 无格式文件,用于以可扩展的格式导出重叠矩阵、核哈密顿矩阵及双电子积分等数据。其结构记录于 *Interfacing to Gaussian 16* 中。

脚本运行结束、结果被读取后,Gaussian 会删除所有这些文件。也可以在脚本后添加其他参数:External="RunTink Amber"。在此示例中,实际执行的命令为:

**$ RunTink Amber** *layer InputFile OutputFile MsgFile FChkFile MatElFile*

指定的脚本总是将上述参数作为其最后六个参数接收。

#### 5.27.2 文件格式

输入文件格式 输入文件格式如下:*#atoms derivatives-requested charge spin* *atomic# x y z MM-charge* 对每个原子重复。第一行指定分子中的原子数、需要计算的导数(0 = 仅能量,1 = 一阶导数,2 = 二阶导数),以及分子的电荷与自旋多重度(格式 4I10)。其余各行给出每个原子的原子序数、坐标以及分子力学电荷(格式 I10, 4F20.12)。

输出文件格式 输出文件为固定格式,包含以下数据(均为原子单位):

**ItemsPseudo CodeLine Format**

*energy, dipole-moment (xyz)*E, Dip(I), I=1,34D20.12 *gradient on atom (xyz)*FX(J,I), J=1,3; I=1,NAtoms3D20.12 *polarizability* Polar(I), I=1,63D20.12 *dipole derivatives* DDip(I), I=1,9*NAtoms3D20.12 *force constants* FFX(I), I=1,(3*NAtoms*(3*NAtoms+1))/23D20.12

仅当请求了一阶导数或频率时,才会出现第二部分;仅当请求了频率时,才会出现最后一部分。在后一种情况下,Hessian 以下三角形式给出:α *ij*,*i*=1 至 *N*,*j*=1 至 *i*。若偶极矩、极化率及偶极导数不可用,则可以为零。

#### 5.27.3 选项

也可以将单电子或单电子与双电子积分及其他矩阵元提供给外部程序,并从该程序中回收 MO 或密度等结果。完整细节与示例位于 *g16/doc* 子目录(Windows 上为 *doc* 文件夹)中。选项必须写在脚本名之后。测试作业 769 可作为其中部分选项的示例。

**InUnf**

将一个 Fortran 无格式文件提供给外部程序,其中包含坐标与单电子矩阵元(重叠、核哈密顿等)。关于该文件内容的细节请参阅 *g16/doc/unfdat.txt*;读取该文件并打印其内容的示例程序见 *g16/doc/rdmat.F*。1Elintegrals 是此选项的同义词。

**2ElIntegrals**

Fortran 无格式文件中还应包含双电子积分。此选项隐含 SCF=Conventional。

**InputFchk**

应生成格式化检查点文件并提供给外部程序。

**OutputUnf**

将一个 Fortran 无格式文件提供给外部程序,由外部程序更新或替换为相同结构的文件,G16 将读取该文件以获得结果,从而替代外部程序/脚本默认预期的文本输出文件。

**IOFchk**

将生成一个格式化检查点文件并提供给外部程序,之后将读取新的 *.fchk* 文件以导入结果。

**ReadInputSection**

此选项可用于修改 Gaussian 为外部脚本自动生成的外部文本输入文件内容。当 Gaussian 与外部脚本之间的数据传递通过上述某个选项完成(例如 IOFchk)时,无需默认的外部文本输入文件。使用此选项时,将从 Gaussian 输入文件中读取一个段(由常规空行界定)。该段中的文本将被放入外部文本输入文件中,以替代该文件通常的内容。这为向外部脚本提供额外指令提供了更大的灵活性。

**Files**

将指定的 Gaussian 内部文件内容包含在生成的矩阵元文件中。例如,以下选项:

```
External=Files=(123,(456,offset=1,integer=27))
```

将使内部文件 123 的内容(默认假定为实数值)被包含在矩阵元文件中(标记为"File 123")。文件列表中的第二项指定内部文件 456 中从第一个(8 字节)字之后开始的 27 个整数(标记为"File 456 integers section 001"),以及整数之后的任何实数值(标记为"File 456 reals section 002")。

#### 5.27.4 相关信息

外部脚本也可以作为 ONIOM 关键字的模型之一来指定(见示例)。Gaussian 独立的 mm 实用程序可以使用 **-external** 开关运行,该开关使其以 External 接口所用的格式读写数据。有关与其他程序交换数据的信息,参见 *Interfacing to Gaussian 16*。

#### 5.27.5 示例

以下路由段为三层 ONIOM 计算的低层指定外部脚本:

```
#ONIOM(B3LYP/6-31G(d):AM1:External="RunTinkAmber")Opt
```

以下路由段为两层 ONIOM 作业的高精度层指定外部脚本:

```
#ONIOM(External="RunCCSDT":B3LYP/6-31G(d))Opt
```
