### 5.59 Output(输出)

Output 关键字最常用于为各种外部程序创建输入文件。它也可以写出包含计算结果的 Fortran 非格式化文件。其选项用于控制所创建文件的内容。

#### 5.59.1 选项

**WFN**

写出 PROAIMS 波函数(*.wfn*)文件。所创建文件的名称在单独一行中从输入流读取。PSI 是 WFN 的同义词。

**WFX**

写出较新版本 AIMPAC 所使用的波函数文件(*.wfx* 文件)。所创建文件的名称在单独一行中从输入流读取。WfnX 是 WFX 的同义词。

**GIAOCx**

在 *.wfn* 或 *.wfx* 文件中包含 GIAO Cx。

**CSGTCx**

在 *.wfn* 或 *.wfx* 文件中包含 CSGT Cx。

**Pickett**

以 Pickett 程序输入的形式,将用于超精细谱的 g 张量及其他张量(文献 [602–607])写入输出文件(参见文献 [608],网址 `spec.jpl.nasa.gov`)。Gaussian 可以计算以下张量(文献 [410, 413–415, 609, 610]):

- 核电四极矩常数:所有作业
- 转动常数:Freq=(VibRot[,Anharmonic])
- 四次离心畸变项:Freq=(VCD,Anharmonic)
- 电子自旋转动项:NMR
- 核自旋转动项:NMR
- 偶极超精细项:所有作业
- Fermi 接触项:所有作业

**SpinRotation**

NMR Output=Pickett 的同义词。包含所有无需进行振动频率计算即可计算的超精细张量。

**RotationalConstants**

Freq=VibRot Output=Pickett 的同义词。包含仅需进行谐振动频率计算即可计算的几乎所有超精细张量。对于 HF 和 DFT,可以组合使用上述两个选项。Output=(RotatationalConstants, Spin-Rotation) 包含所有仅需二阶导数即可计算的张量。它等价于 Freq=(VCD,VibRot) Output=Pickett。

**QuarticCentrifugal**

Freq=(VibRot,Anharm) Output=Pickett 的同义词。包含四次转动-振动耦合,但不包含须单独计算的自旋转动张量。

**ReadAtoms**

读取要包含在 Pickett 程序输入中的原子列表(注意该程序只接受八个原子核的张量)。原子编号以自由格式指定,该输入段以空白行结束。默认情况下,程序会自动选择八个感兴趣的原子。

与 Gaussian 接口相关的选项(Gaussian Interfacing-Related Options)

**MatrixElement**

要求生成供与其他程序接口的文本数据文件。RawMatrixElement 要求生成二进制矩阵元文件。详见 *Interfacing to Gaussian 16*。

**I4Labels**

与 MatrixElement 选项联用时,写入矩阵元文件使用 Integer*4 数值,而不是当前 Gaussian 的整数大小。

**MO2ElectronIntegrals**

与 MatrixElement 选项联用时,写入矩阵元文件时包含 MO 基下的双电子积分。若要在矩阵元文件中包含 AO 基下的双电子积分,请将此选项与 SCF=Conventional 联用。

**DerivativeDensities**

与 MatrixElement 选项联用时,写入矩阵元文件时包含来自 CPHF 的导数密度。

**GIAOInts**

与 MatrixElement 选项联用时,写入矩阵元文件时包含 GIAO L/R**3 和 d2H/dBdm 单电子积分导数。

**Files**

与 MatrixElement 选项联用时,将指定的 Gaussian 内部文件内容包含在生成的矩阵元文件中。例如,以下选项:

```
Output=(Matrix,Files=(123,(456,offset=1,integer=27)))
```

将使内部文件 123 的内容(默认假定为实数值)被包含在矩阵元文件中(标记为 "File 123")。文件列表中的第二项指定内部文件 456 中第一个(8 字节)字之后的 27 个整数(标记为 "File 456 integers section 001"),以及整数之后的任何实数值(标记为 "File 456 reals section 002")。
