### 5.41 GVB(广义价键)

本方法关键字请求进行完美配对广义价键(GVB-PP)计算。GVB 需要一个参数:要拆分的完美配对对数;例如:GVB(4)。该参数也可以通过 NPair 选项指定。GVB 对的自然轨道取自初始猜测行列式的占据轨道和虚轨道(见*输入*标签页)。

#### 5.41.1 输入

通常,GVB-PP 计算中最困难的输入是指定初始猜测(Link 401)。这通常包括修改轨道以确保正确识别高自旋、完美配对和闭壳层轨道,并可能降低 SCF 对称性,以容纳通常代表 GVB-PP 最低能量解的定域轨道。GVB 程序读取每个 GVB 对中的轨道数(格式 40I2)。读取的行数是固定的(通常为 1),因此不需要终止空行。对于自旋多重度为 S、含有 N 个 GVB 对、且每对中轨道数为 *n* 1, ···, *nN* 的分子,GVB 程序按如下方式使用初始猜测中的轨道:

- 初始猜测中最高的 S-1 个占据轨道(在 ROHF 计算中本应为单占据)成为高自旋轨道。
- 接下来的 *N* 个占据轨道(在 ROHF 计算中本应为双占据)成为各 GVB 对的第一个自然轨道。
- 猜测中其余被占据的轨道保持闭壳层。
- 最低的 *n* 1
- 1 个虚轨道依次成为第一个 GVB 对的自然轨道 2 至 *n* 1,然后接下来的 *n* 2 −1 个轨道分配给第 2 对,依此类推。GVB-PP 方案不允许一个轨道被多个 GVB 对共享。
- 初始猜测中剩余的(虚)轨道成为 GVB 计算中的虚轨道。通常需要 Guess=Alter 以确保作为第一自然轨道的猜测占据轨道与将成为相应较高自然轨道的正确猜测虚轨道相匹配。通常先从 Guess=(Local,Only) 开始,检查轨道以确定需要的修改,然后使用 Guess=(Local,Alter) 和 GVB(NPair=N,Freeze),使较高的自然轨道更加合适。最后,可以使用 Guess=Read 运行完整计算,并在 GVB 中优化所有轨道。如果对轨道破缺对称性存在任何疑虑或顾虑,应使用 Symm=NoSCF 进行计算,并首先使用 Guess=Local。事实上,除非是非常专业的用户,通常推荐这种方法。如果某对中的轨道数为负,则读取该对所用 CI 的根以及该对的初始 GVB 系数,格式为 (I2,5D15.8)。如果一个 1Σ 或 1∆ 态表示为形式 *x* 2 ±*y* 2 的 GVB 对,这将非常有用。

#### 5.41.2 选项

**NPair**

给出完美配对对的数目。GVB(*N*) 等价于 GVB(NPair=*N*)。NPair=0 是可接受的,结果为闭壳层或自旋限制的 SCF 计算。

**InHam=_N_**

读入 N 个哈密顿量(Fock 算符,即耦合系数集合)。该选项可与完美配对对组合使用。每个哈密顿量按以下语法读入(格式见括号):*NO# 当前哈密顿量中的轨道数 (I5)* *FjOccup. # 占据数 (1.0=闭壳层) (D15.8)* *(AJ(I), I =1,NHam)J 系数 (5D15.8)* *(AK(I), I =1,NHam)K 系数 (5D15.8)*。目前不支持将具有相同 *AJ* 和 *AK* 系数的多个轨道合并为一个"壳层",因此 *NO* 始终为 1。*ham506* 实用程序可用于为原子计算中常见的球面平均情形生成平均哈密顿量。哈密顿量系数在 Bobrowicz 和 Goddard [472] 中有所描述。关于 GVB 波函数定性解释的良好入门,可参见 Goddard 和 Harding [473] 的综述文章。

**OSS**

做一个双电子、双正交轨道的开壳层单重态。该选项可与完美配对对组合使用。OpenShellSinglet 是 OSS 的同义词。

**Freeze**

冻结闭壳层和开壳层轨道以及 GVB 对的第一自然轨道,只允许第 2 及更高的轨道变化。该选项对于开始处理困难的波函数很有用。

#### 5.41.3 可用性

能量、解析梯度和数值频率。

#### 5.41.4 示例

以下是对单重态亚甲基进行的 GVB(3/6) 计算:

```
#GVB(3)/6-31G(d)Pop=Full
Guess=(Local,LowSym,Alter)
GVB(3)onCH2
moleculespecification
1 4 0 2 3 9 Guess=LowSym input
```

`2,3` *Guess=Alter 输入*

```
2 2 2 GVB input
```

每个 3 个价电子对都被拆分为一个 GVB 对。进行了一次初步的 Guess=Only 计算,以确定定域轨道以及需要进行的修改。完美配对 GVB 方法包括对*对内*相关的影响,但不包括*对间*相关的影响。因此,GVB 电子对倾向于定域化。对于单重态亚甲基,即使在 Hartree-Fock 水平上,碳的孤对电子也是定域的。C-H 键的正则 Hartree-Fock 轨道离域为线性组合 (C-H1 + C-H2) 和 (C-H1 – C-H2),分别具有 A1 和 B2 对称性。为了使猜测中的定域化产生独立的键对,必须组合这两个不可约表示。

表示必须被组合。类似地,GVB 计算本身必须被告知不要对轨道施加完整的分子对称性,否则会迫使它们离域。将 A1 和 B2 表示组合、以及将 A2 和 B1 表示组合,会使计算仅对各个轨道施加 *Cs* 对称性,从而允许每个键有独立的 GVB 对。由于每个键的对将是等价的,最终的总波函数和密度仍具有 *C* 2 *v* 对称性。Guess=LowSymm 关键字指定在 GVB 计算所使用的对称性信息中,分子点群的不可约表示将被组合。它需要单独一行输入,给出要组合的不可约表示的编号,这些编号对应于它们在输出文件中列出的顺序(它们紧跟在标准取向之后出现)。例如,以下是一个具有 *C* 2 *v* 对称性的分子的输出:

```
Thereare4symmetryadaptedbasisfunctionsofA1symmetry.
Thereare0symmetryadaptedbasisfunctionsofA2symmetry.
Thereare1symmetryadaptedbasisfunctionsofB1symmetry.
Thereare2symmetryadaptedbasisfunctionsofB2symmetry.
```

因此,对于 *C* 2 *v* 对称性,顺序为 A1、A2、B1、B2,在 Guess=LowSym 输入中分别称为 1 至 4。零分隔不同的表示组,九结束列表。因此,要将 A1 与 B2 组合、A2 与 B1 组合,从而将 SCF 对称性降低为 *Cs*,适当的输入行为:

```
140239
```

由于此信息始终只需一行,因此本节不需要空行终止。在第一个作业步骤中初始猜测定域化后,占据轨道的顺序为 C-1s C-H1 C-H2 C-2s,最低虚轨道的顺序为 C-2p C-H1* C-H2*。因此,如果不交换轨道,C-2s 孤对将被正确地与未占据的 p 轨道配对,但随后的下一个较低占据轨道 C-H2 将与下一个较高的虚轨道 C-H1* 配对。因此,必须交换两个键占据轨道或两个键虚轨道,才能使轨道正确匹配。最后,送入 GVB 程序的一行输入表明,3 个 GVB 对中每对有 2 个自然轨道。
