### 5.68 Restart(重启)

该关键字用于重启先前失败的作业。此方法主要用于涉及大量中间数据的长时间作业:若将重启数据保存到检查点文件中,检查点文件会大到难以管理,从而违背将检查点文件与读写文件分开的初衷。该过程依赖于为读写文件命名,使其在作业异常终止时被保留,然后用它来重启。例如,对于频率计算,需要包含以下 Link 0 命令:

```
%RWF=myrwf
%NoSave
%Chk=mychk
```

`#P Freq` ···

*输入继续*···

默认情况下,凡是以 % 行命名的文件,在作业结束时都会被保留。RWF 之后的 %NoSave 会覆盖这一默认行为,使读写文件在作业正常结束时仍被删除(但若作业提前终止,则会保留)。需要注意以下几点:

- 检查点文件在作业结束后通常很有用,因此一般将其放在 %NoSave 之后。
- 读写文件可能非常大,应放在合适的文件系统上。例如,检查点文件可以放在普通用户目录中,该目录可能只有适量的可用空间和/或为 NFS 挂载;而对于值得重启的大型作业,读写文件应放在大型本地临时文件系统上。
- 可重启的作业是指在完成之前执行被中止的作业。以收敛失败或超过优化步数等错误信息结束的作业需要用户介入。

#### 5.68.1 可用性

解析频率计算(包括 ONIOM 下的 ROA 和 VCD 等性质);CCSD 和 EOM-CCSD 计算;NMR;Polar=OptRot;CID、CISD、CCD、QCISD 和 BD 能量。计算多个几何结构的作业(如几何优化、IRC 和数值频率计算)更适合像前面那样从检查点文件直接重启。

#### 5.68.2 相关关键字

Freq, EOM

#### 5.68.3 示例

以下输入文件将重启按上述方式设置的作业:

```
%RWF=myrwf
%NoSave
```

```
%Chk=mychk
#PRestart
```

路由段中无需其他关键字,也无需其他输入。
