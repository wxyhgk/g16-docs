### 5.60 PBC(周期性边界条件)

此关键字允许您为周期性边界条件(Periodic Boundary Conditions, PBC)作业指定选项。注意,只要在输入结构中包含平移矢量,PBC 即自动开启;本关键字仅用于控制 PBC 计算的执行方式。如果不需要其中任何选项,则无需包含该关键字即可进行 PBC 计算。

#### 5.60.1 选项

**GammaOnly**

仅计算 Γ 点(k=0),而不进行完整的 k 点积分。

**NKPoint=_N_**

计算大约 *N* 个 k 点。

**CellRange=_N_**

在设置镜像晶胞时,沿每个方向延伸 *N* 玻尔。

**NCellMin=_N_**

至少包含 *N* 个晶胞。

**NCellMax=_N_**

在计算的任何部分中至多包含 *N* 个晶胞。

**NCellDFT=_N_**

在 DFT 交换-相关积分求积中至少包含 *N* 个晶胞。NCellXC 是此选项的同义词。

**NCellK=_N_**

在精确交换中至少包含 *N* 个晶胞。默认情况下,若包含精确交换,则该数值为用于重叠相关量和交换-相关求积的晶胞数的两倍。

#### 5.60.2 可用性

适用于 HF 和 DFT 的解析能量与几何优化,以及数值频率(不提供红外强度)。不适用于 SCRF 或 Charge。对于任何合理规模的周期性体系,只有在使用纯 DFT 泛函并结合密度拟合时,才可能获得可接受的性能。

#### 5.60.3 示例

周期性体系以普通分子规格定义晶胞。唯一额外需要的输入是附加在分子规格之后(中间不能有空行)的一个、两个或三个平移矢量,用以指示复制方向。例如,以下输入为新戊二烯(neoprene)指定了一维 PBC 单点能计算:

```
#PBEPBE/6-31g(d,p)/AutoSCF=Tight
neoprene,-CH2-CH=C(Cl)-CH2-optimizedgeometry
01
C,-1.9267226529,0.4060180273,0.0316702826
H,-2.3523143977,0.9206168644,0.9131400756
H,-1.8372739404,1.1548899113,-0.770750797
C,-0.5737182157,-0.1434584477,0.3762843235
H,-0.5015912465,-0.7653394047,1.2791284293
C,0.5790889876,0.0220081655,-0.3005160849
C,1.9237098673,-0.5258773194,0.0966261209
H,1.772234452,-1.2511397907,0.915962512
H,2.3627869487,-1.0792380182,-0.752511583
Cl,0.6209825739,0.9860944599,-1.7876398696
TV,4.8477468928,0.1714181332,0.5112729831
```

最后一行指定了平移矢量。注意此处以 TV 作为原子符号。以下分子规格可用于石墨片层上的二维 PBC 计算:

```

C0.0000000.0000000.000000
C0.0000001.4291180.000000
TV2.4753150.0000000.000000
TV-1.2199522.1334470.000000
```
