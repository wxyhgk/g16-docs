### 5.12 ChkBasis(从检查点文件读取基组)

ChkBasis 关键字要求从检查点文件中读取基组。它在包含通用基组的复合作业中很有用,因为这样输入流中只需保留一份基组副本。但需要注意,ChkBasis 可以读取检查点文件中*任何*已存在的基组,而不论其最初是如何指定的。基组中指定的 ECP 也会被读取,纯函数与笛卡尔函数的选择同样会被读取。默认情况下,ChkBasis 也会读取检查点文件中的任何密度拟合基组。其他用法见示例。使用 ChkBasis 时不应再指定任何基组关键字。CheckBasis、CheckPointBasis、ReadBasis 和 RdBasis 均为 ChkBasis 的同义词。

#### 5.12.1 相关关键字

Gen, GenECP, Pseudo, ExtraBasis, ExtraDensityBasis

#### 5.12.2 示例

下列路由段将从检查点文件中读取基组以及密度拟合基组(如有),并将其用于当前作业:

```
#B3LYP/ChkBasis
```

下列路由段仅从检查点文件中读取基组,密度拟合基组将自动生成:

```
#B3LYP/ChkBasis/Auto
```

下列路由段仅从检查点文件中读取密度拟合基组:

```
#B3LYP/6-31G(d)/ChkBasis
```
