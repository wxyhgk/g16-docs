### 5.56 NMR（核磁共振）

该性质关键字使用 Hartree-Fock 方法、所有 DFT 方法以及 MP2 方法预测 NMR 屏蔽张量和磁化率 [552–555]。NMR 屏蔽张量可采用连续规范变换（CSGT, Continuous Set of Gauge Transformations）方法 [555–557] 以及规范无关原子轨道（GIAO, Gauge-Independent Atomic Orbital）方法 [215, 555, 558–560] 计算。磁化率也可以同时使用 GIAO [561] 和 CSGT 计算。Gaussian 还支持 IGAIM

方法 [556, 557]（CSGT 方法的一种略有变化的形式），以及单原点（Single Origin）方法，二者均可用于屏蔽张量和磁化率的计算。用于 NMR 计算的结构应当已在较好的理论水平下优化。注意，CSGT 计算需要大基组才能获得精确结果。自旋-自旋耦合常数也可以在 NMR 作业中计算 [562–566]，使用 SpinSpin 选项即可。

#### 5.56.1 选项

**SpinSpin**

除通常的 NMR 性质外，同时计算自旋-自旋耦合常数。请注意，该计算类型的计算成本约为单独计算振动频率的两倍。仅适用于 Hartree-Fock 和 DFT 方法。

**Mixed**

请求两步法自旋-自旋耦合计算 [566]。该选项会运行两个作业步骤。第一步中，将用户指定的基组修改为适用于费米接触项的形式：对基组进行去收缩（uncontract），并为核心添加紧致极化函数。第二步中，使用路由段中指定的未修改基组计算自旋-自旋耦合的其余三项。第二作业步骤末尾报告的最终结果包含第一步的费米接触贡献。这能显著提高自旋-自旋耦合常数的精度，尤其是在使用典型的价层基组（如 6-311G+(d,p)、aug-CC-pVDZ 或 aug-CC-pVTZ）时。与使用包含紧致极化函数的修改基组计算全部四项相比，该方法也更快。

**ReadAtoms**

仅为选定原子计算自旋-自旋耦合常数。原子列表在单独的输入段中指定（以空行结束）。该列表初始为空。输入段采用以下格式：**atoms**=*list* [**notatoms**=*list*]，其中每个 *list* 是以逗号或空格分隔的原子编号、原子编号范围和/或原子类型的列表。关键字按顺序依次生效。以下为示例：

```
atoms=3-6,17 notatoms=5 Adds atoms 3, 4, 6 and 17 to the atom list. Re-
```

*若存在则移除 5。*

```
atoms=3 C 18-30 notatoms=H Adds all C atoms and all non-H among atoms 3,
```

*18–30 号原子。*

```
atoms=C N notatoms=5 Adds all C and N atoms except atom 5.
atoms=1-5 notatoms=H atoms=8-10 Adds atoms 8-10 and non-hydrogens among
```

*1–5 号原子。*

不带关键字的裸整数被解释为原子编号：

```
1,3,5 7 Adds atoms 1, 3, 5 and 7.
```

**CSGT**

仅使用 CSGT 方法计算 NMR 性质。可通过 NMR=CSGT IOp(10/93=1) 生成 ACID 程序的数据文件。

**GIAO**

仅使用 GIAO 方法计算 NMR 性质。这是默认设置。

**IGAIM**

以原子中心作为规范原点。

**SingleOrigin**

使用单一规范原点。该方法仅用于比较目的，一般不推荐使用。

**All**

分别使用 SingleOrigin、IGAIM 和 CSGT 三种方法计算性质。

**PrintEigenvectors**

输出每个原子屏蔽张量的本征向量。

**FCOnly**

仅计算费米接触自旋-自旋项。

**ReadFC**

从检查点文件中读取费米接触自旋-自旋项，然后计算其余的自旋-自旋耦合项。

**Susceptibility**

在计算屏蔽的同时计算磁化率。

#### 5.56.2 可用性

SCF、DFT 和 MP2 方法。NMR 可与 SCRF 结合使用。对于 HF 和 DFT，NMR 与 Freq 现在可以同时出现在同一路由段中。
