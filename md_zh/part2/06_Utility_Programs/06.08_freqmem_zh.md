### 6.8 freqmem(频率计算内存估算工具)

freqmem 实用程序接收频率计算的参数,并确定以最高效率一次性完成所有步骤所需的内存量。所有参数都必须在命令行上提供,语法如下:freqmem *natoms nbasis* r|u *function*

各参数含义如下:

**_natoms_**

分子中的原子数。

**_nbasis_**

所选基组下该体系的基函数数目。

**r|u**

单个字母代码,分别表示 RHF(闭壳层)或 UHF(开壳层)计算,视情况而定。

**_function_**

表示基组中最高角动量基函数的字母:即 d 表示 d 函数,f 表示 f 函数,h 表示 h 函数,依此类推。该参数也可以是表示所用基组中基函数类型的字符串:sp、spd 或 spdf(为早期版本的该实用程序所使用的形式)。

#### 6.8.1 示例

以下示例估算在紫杉醇(113 个原子)上进行 RHF/STO-3G 频率计算所需的内存资源:

**$ freqmem 113 361 r p**

```
RHFdirectfrequencieswithspfunctions:
Onepassrequires44.80megawords.
```

输出表明,程序将需要约 360 MB 的内存,才能在一次遍历中完成频率计算。如果无法提供 freqmem 指定的内存量,仍然可以通过多次遍历完成频率计算。使用 %Mem Link 0 命令指定可用内存。将该参数设置为 freqmem 建议内存量的二分之一或三分之一通常是一个不错的选择。Gaussian 计算中使用的基函数数目会在输出文件的早期部分打印出来。也可以通过为相应作业设置输入文件并包含 %KJob=301 Link 0 命令来计算该数目,该命令会让程序在到达 Link 301 时立即终止(几乎立刻就会到达)。随后可以使用如下命令从日志文件中获取指定基组下该分子所用的基函数数目:

**$ grep "basis func" _name_.log**

```
361basisfunctions1083primitivegaussians
```
