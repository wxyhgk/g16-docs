### 6.3 cubegen(立方体文件生成工具)

Gaussian 包含一个独立的实用程序,用于从格式化检查点文件中的数据生成立方体文件(等同于之前的 Cube 关键字)。该实用程序名为 cubegen,其语法如下:

**cubegen** *nprocs kind fchkfile cubefile npts format cubefile2*

各参数不区分大小写,含义如下:

**_nprocs_**

用于静电势计算的共享内存处理器数量。取值为 0 等同于 1(即默认值)。注意,如果指定了其他参数,则必须包含此参数。此前该参数曾用于指定分配的内存量,现在应改用 GAUSS_MEMDEF 环境变量。

**_kind_**

指定要生成的立方体类型的关键字:

MO=*n* 第 *n* 号分子轨道。也可使用关键字 Homo、Lumo、All、OccA(所有占据的α轨道)、OccB(所有占据的β轨道)、Valence(所有价轨道)和 Virtuals(所有虚轨道)代替具体的轨道编号。*n* 没有默认值,省略时将报错。AMO 和 BMO 可类似地用于分别仅选择α或β轨道。对于开壳层体系,Homo 同时选择α和β轨道。Density=*type* 指定类型的总密度。*type* 关键字为 Density 关键字有效的单一密度选项之一:SCF、MP2、CC、CI 等(注意,不支持 Current)。fdensity、falpha 和 fbeta 形式表示使用全部而非冻结核密度。默认为 SCF。Spin=*type* 指定类型的自旋密度(α与β密度之差)。Alpha=*type* 指定类型的α自旋密度。Beta=*type* 指定类型的β自旋密度。Potential=*type* 使用指定类型密度计算的静电势。Gradient 计算密度及其梯度。Laplacian 计算密度的拉普拉斯算子(∇2ρ)。NormGradient 计算每个点处密度梯度的模。CurrentDensity=*I* 磁致(GIAO)电流密度的大小,其中 *I* 为外加磁场方向(X、Y 或 Z)。ShieldingDensity=*IJN* 磁屏蔽密度。*I* 为外加磁场方向,*J* 为感应场方向(X、Y 或 Z),*N* 为计算屏蔽密度(GIAO)所针对的原子核编号。

**_fchkfile_**

格式化检查点文件的名称。如果未指定,cubegen 将提示输入该文件名。

**_cubefile_**

输出立方体文件的名称;若未明确指定,默认为 test.cube(即指定检查点文件名并不会改变默认的立方体文件名)。

**_npts_**

立方体每边的点数。取值为 0 时选择默认值 803,即在程序自动生成的矩形网格(不一定是立方体)上均匀分布 803 个点。正值 *npts* 同样指定每个"边"上的点数;例如,100 表示 1,000,000(100³)个点的网格。取值 -2、-3 和 -4 分别对应关键字 Coarse、Medium 和 Fine,以及每 Bohr 3 个点、6 个点和 12 个点(依次对应)。负值 *npts* ≤ -5 表示点之间的间距为 *npts*×10⁻³ 埃。取值 -1 表示根据以下格式,从输入流或第二个立方体文件(见下文)读取立方体规格:

*IFlag, X* 0*, Y* 0*, Z* 0 *输出单元号和起始点。* *N* 1*, X* 1*, Y* 1*, Z* 1 *X 方向的点数和步长。* *N* 2*, X* 2*, Y* 2*, Z* 2 *Y 方向的点数和步长。* *N* 3*, X* 3*, Y* 3*, Z* 3 *Z 方向的点数和步长。*

*IFlag* 为输出单元号。若 *IFlag* 小于 0,则生成格式化文件;否则写出非格式化文件。若 *N* 1<0,则输入的立方体坐标视为 Bohr 单位,否则视为埃。无论如何,都使用 |*N* 1| 作为 X 方向的点数;*N* 2 和 *N* 3 分别指定 Y 和 Z 方向的点数。注意,三个坐标轴按指定方式使用,不做正交化处理,因此网格不必是矩形。取值 -5 表示从标准输入读取任意点列表。若手动输入,需以文件结束符(即 Unix 下的 Ctrl-D)结束输入。或者,也可将标准输入重定向到包含点列表的文件(文件末尾不要留空行或 Ctrl-D)。

**_format_**

格式化输出文件的格式:h 表示包含文件头(默认);n 表示不包含文件头。生成非格式化立方体文件时,此参数被忽略。

**_cubefile2_**

若指定,则生成的立方体尺寸取自此文件。此选项适用于之后进行算术运算(如差分密度)时生成立方体。要使立方体尺寸取自指定的立方体文件,npts 参数必须为 -1,且指定的文件必须是带文件头创建的。若未指定任何参数,cubegen 将提示输入 fchkfile,并运行以下命令:

**cubegen 1 density=scf test.cube 80 h**

该命令将生成名为 test.cube(带文件头)的文件,其中包含 SCF 密度,网格为 803 个点的矩形网格。

#### 6.3.1 输出文件格式

立方体文件中的所有数值均以原子单位表示,与输入单位无关。密度、密度梯度的模、密度的拉普拉斯算子以及势均为标量(即每个点一个值,*NVal*=1)。梯度立方体包含密度加上密度的矢量梯度,因此每个点有四个值(*NVal*=4):即密度值加上其梯度的 X、Y、Z 分量。立方体文件每行一条记录(即 *N* 1×*N* 2 条记录,每条长度为 *N* 3×*NVal*)。对于格式化输出,每行以格式 (6E13.5) 写出。在这种情况下,若 *N* 3×*NVal* 不是 6 的倍数,某些行中可能存在空白。例如,立方体文件大致如下所示:

*NAtoms, X-Origin, Y-Origin, Z-Origin, NVal  NVal 为每个点的值的个数* *N1, X1, Y1, Z1  最慢变化方向的增量个数* *N2, X2, Y2, Z2* *N3, X3, Y3, Z3  最快变化方向的增量个数* *IA1, Chg1, X1, Y1, Z1  第一个原子的原子序数、电荷和坐标* ··· *IAn, Chgn, Xn, Yn, Zn  最后一个原子的原子序数、电荷和坐标* *(N1×N2) 条记录,每条长度为 N3×NVal  网格中各点的密度值*

注意,每条记录各自单独写入。对于分子轨道输出,*NAtoms* 将小于零,并且在最后一个原子的数据之后会有一条额外记录(若文件为格式化文件,格式为 10I5):*NMO, (MO(I),I=1,NMO)  轨道数及其编号* 若计算了 *NMO* 个轨道,则每条记录长度为 *NMO*×*N* 3,并且包含每个点上所有轨道的值(此时 *NMO*=*NVal*)。

#### 6.3.2 使用 Fortran 程序读取立方体文件

若要将立方体文件中的值读回数组 X(*NVal*,*N* 3,*N* 2,*N* 1) 中,可以使用如下 Fortran 循环代码:

```
Do10I1=1,N1
Do10I2=1,N2
Read(n,’(6E13.5)’)((X(IVal,I3,I2,I1),IVal=1,NVal)I3=1,N3)
10Continue
```

其中 *n* 为与立方体文件对应的单元号。
