### 6.7 freqchk(频率与热化学数据提取工具)

freqchk 实用程序用于从检查点文件中提取频率和热化学数据,并可选择指定其他温度、压力、标度因子和/或同位素替换。

freqchk 命令的完整语法如下:

**$ freqchk** *checkpoint-file* [*options*] [*answers to prompts*]

若检查点文件名不包含扩展名,则默认为 .fchk;格式化和非格式化检查点文件均可接受。

#### 6.7.1 选项

支持以下选项:

**-o _filename_**

将输出发送到指定文件。默认情况下,输出显示在屏幕上。

**-nfd**

跳过对完整(3N<sub>atoms</sub>)²矩阵的对角化(与 Freq=NoDiagFull 相同)。

**-sel**

选择要纳入的简正模式。程序会像平常一样提示所需信息,然后暂停,以便您输入所需的模式(不再进行提示)。您可以像 Freq=ReadNormalModes 一样指定模式编号和/或原子列表。参见下面的示例。

**-read**

从检查点文件中读取简正模式,而不是重新计算。

**-save**

保存简正模式;仅适用于二进制检查点文件。与 -sel 结合使用时,检查点中将只保留所选模式,以供后续 -read 操作使用。

**-np=_N_**

使用 N 个处理器进行频率分析。

随后输出频率结果,其反映了上面指定的数值。注意,如果指定了标度,则只有热化学数据会反映该标度;频率本身不会被标度。在 freqchk 会话中,有时还会出现一个额外的提示:

```
Projectoutgradientdirection?[N]
```

当受力显著不为零时会出现此提示。受力不为零的一个可能原因是频率是在 IRC 上的某一点计算的,因此投影掉梯度方向可能会有所帮助。如果在其他情况下受力不为零,则该结构不是驻点,应对其几何进行优化,以获得有意义的振动分析。然而,如果您只是想查看频率,例如检查优化起点的曲率是否正确,则不应投影掉梯度方向。作为交互模式的替代方式,您可以在命令行上指定所有 freqchk 输入,如下例所示,它执行与上述最后一个交互会话相同的操作:

**$ freqchk solvent.chk N 300 1.5 1 N N**

若倒数第二个参数为 N,则程序会提示输入同位素。最后一个参数是对梯度方向提示的回答(如果该提示出现);若省略该参数且提示相关,程序将提示您输入。**选择模式。** 以下命令及输入选择模式 1–5 以及所有其他涉及氮原子的模式,并将输出发送到文件 ala_freq.out:

**$ freqchk ala.chk -sel -o ala_freq.out N 0 0 0 N N**

**1-5 atoms=N**

*输入以空行结束。*

**$ more ala_freq.out** *频率数据已可供查看。*
