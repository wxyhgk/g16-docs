### 5.70 Scale

Specifies the frequency scale factor to be used for thermochemistry analysis. The value should be specified as an option: `#` ··· `Scale=0.95` The default is 1.0 except for compound methods where the scale factor is implicit in being the definition of the method used.

#### 5.70.1 Options

**Default**

Restores the default scale factor for harmonic frequencies if a different value was retrieved by Geom=AllCheck.
